# 4.5 Render and export

**Specifies:** [4.5 Render and export](/knowledge/DFD_LEVEL3_TLM_RENDER) and the six processes it decomposes into
**Implemented by:** `TipsLadderManager/index.html`, `TipsLadderManager/src/render.js`, `TipsLadderManager/src/drill.js`, `TipsLadderManager/src/popup.js`, `TipsLadderManager/src/modal.js`

Draw the result of the mode on screen, Build or Rebalance, and write it out. The two modes have different interfaces and different results. The code that more than one of the six processes calls is in the shared modules [drill.js (M6)](../../knowledge/SharedModules.md#m6), [popup.js (M7)](../../knowledge/SharedModules.md#m7) and [modal.js (M8)](../../knowledge/SharedModules.md#m8). [6.0 UI Layout](./6.0_UI_Layout.md) states where each control is.

| Process | What it specifies |
|---|---|
| [4.5.1 Render ladder table](./4.5.1_Render_Ladder_Table.md) | The columns, the group header rows, the sub-rows, the totals row and the per-year DARA input of the ladder table. |
| [4.5.2 Show drill popups](./4.5.2_Show_Drill_Popups.md) | The popup of each drillable cell, the nested drills and the duration popups. |
| [4.5.3 Show trade ticket](./4.5.3_Show_Trade_Ticket.md) | The Trade Ticket of Build and of Rebalance. |
| [4.5.4 Show cash flow calendar](./4.5.4_Show_Cash_Flow_Calendar.md) | The Cash Flow Calendar and its csv file. |
| [4.5.5 Export ladder table](./4.5.5_Export_Ladder_Table.md) | The Ladder CSV. |
| [4.5.6 Export holdings and DARA plan](./4.5.6_Export_Holdings_And_DARA_Plan.md) | The Holdings Export, the `#params` row and the DARA Plan File. |
