# 4.1 Load market data

**Specifies:** [4.1 Load market data](/knowledge/DFD_LEVEL3_TLM_LOAD) and the four processes it decomposes into  
**Implemented by:** `shared/src/market-data.js`, `TipsLadderManager/src/rebalance-lib.js`

TipsLadderManager reads Market quotes (S7) today. FedInvest prices (S1) is a dormant, code-only
cross-check path — [4.1.2](#fetch-and-parse-fedinvest-prices) — never selected in production; it
is documented below but not drawn on [4.1's own Level 3 diagram](/knowledge/DFD_LEVEL3_TLM_LOAD).

## Processes

<a id="fetch-and-parse-market-quotes"></a>
### 4.1.1 Fetch and parse market quotes

**Implemented by:** `shared/src/market-data.js#fetchFidelityTipsData`, `shared/src/fidelity-parse.js#parseFidelityTipsRows`, `shared/src/fidelity-parse.js#parseFidelityDownloadDate`, `shared/src/fidelity-parse.js#fidelityDownloadDateIso`, `shared/src/market-data.js#nextBondTradingDay`, `shared/src/bond-math.js#yieldFromPrice`

Read [Market quotes (S7)](../../knowledge/DataStores.md#s7) and the [TIPS reference data](../../knowledge/DataStores.md#s2) and [Bond Holidays](../../knowledge/DATA_DICTIONARY.md#bond-holiday) that [Fetch auxiliary TIPS data (4.1.3)](#fetch-auxiliary-tips-data) produces, and produce the [TIPS Yields](../../knowledge/DATA_DICTIONARY.md#tips-yields):

- Read the `Date downloaded` footer line and set the [Download Date](../../knowledge/DATA_DICTIONARY.md#download-date) to its date.
- Set the [Settlement Date](../../knowledge/DATA_DICTIONARY.md#settlement-date) to the [Download Date](../../knowledge/DATA_DICTIONARY.md#download-date) advanced one bond trading day past any [Bond Holiday](../../knowledge/DATA_DICTIONARY.md#bond-holiday) (T+1) — a real broker trade settlement.
- For each TIPS row [Market quotes (S7)](../../knowledge/DataStores.md#s7) states (one per CUSIP, first occurrence wins):
  - Set the [Maturity Date](../../knowledge/DATA_DICTIONARY.md#maturity-date) to the row's own value, or to [TIPS reference data](../../knowledge/DataStores.md#s2)'s value for the CUSIP when the row states none.
  - Set the dated date [Ref CPI](../../knowledge/DATA_DICTIONARY.md#ref-cpi) to [TIPS reference data](../../knowledge/DataStores.md#s2)'s value for the CUSIP.
  - If there's no usable ask [Price](../../knowledge/DATA_DICTIONARY.md#price), or no [Maturity Date](../../knowledge/DATA_DICTIONARY.md#maturity-date): the security has no [Yield](../../knowledge/DATA_DICTIONARY.md#yield).
  - Otherwise: calculate the [Yield](../../knowledge/DATA_DICTIONARY.md#yield) from the ask [Price](../../knowledge/DATA_DICTIONARY.md#price) at the [Settlement Date](../../knowledge/DATA_DICTIONARY.md#settlement-date) — the same yield-from-price calculation every other source and app in the portal uses ([bond-math.js (M3)](../../knowledge/SharedModules.md#m3)).

**Output:** the [TIPS Yields](../../knowledge/DATA_DICTIONARY.md#tips-yields), to [Build TIPS market data (4.1.4)](#build-tips-market-data).

<a id="fetch-and-parse-fedinvest-prices"></a>
### 4.1.2 Fetch and parse FedInvest prices

**Implemented by:** `shared/src/market-data.js#fetchTipsData`, `shared/src/csv.js#parseCsv`

**Status: dormant.** This code path exists and works, but `shared/src/market-data.js`'s own source
selector never selects it in production — TipsLadderManager reads Market quotes (S7) exclusively
([4.1.1](#fetch-and-parse-market-quotes)). It is kept as a manual cross-check, and specified here for
that reason, but is not part of the diagram at [4.1's own Level 3](/knowledge/DFD_LEVEL3_TLM_LOAD).

Read [FedInvest prices (S1)](../../knowledge/DataStores.md#s1) and produce the [TIPS Yields](../../knowledge/DATA_DICTIONARY.md#tips-yields):

- Set the [Settlement Date](../../knowledge/DATA_DICTIONARY.md#settlement-date) to the store's own first line.
- Drop every row whose type is not TIPS.
- For each kept row: set the [Maturity Date](../../knowledge/DATA_DICTIONARY.md#maturity-date), [Coupon Rate](../../knowledge/DATA_DICTIONARY.md#coupon-rate), dated date [Ref CPI](../../knowledge/DATA_DICTIONARY.md#ref-cpi), [Price](../../knowledge/DATA_DICTIONARY.md#price) and [Yield](../../knowledge/DATA_DICTIONARY.md#yield) to the values the row itself already states — [FedInvest prices (S1)](../../knowledge/DataStores.md#s1) was written with the [Yield](../../knowledge/DATA_DICTIONARY.md#yield) already calculated ([1.1.3 Calculate yields](../../knowledge/1.1_Download_FedInvest_Prices.md#calculate-yields)).

**Output:** the [TIPS Yields](../../knowledge/DATA_DICTIONARY.md#tips-yields), to [Build TIPS market data (4.1.4)](#build-tips-market-data).

<a id="fetch-auxiliary-tips-data"></a>
### 4.1.3 Fetch auxiliary TIPS data

**Implemented by:** `shared/src/market-data.js#fetchAuxTipsData`, `shared/src/market-data.js#parseTipsRefRows`, `shared/src/csv.js#parseCsv`, `shared/src/settlement.js#parseHolidaySet`

Read [Ref CPI (S3)](../../knowledge/DataStores.md#s3), [TIPS reference data (S2)](../../knowledge/DataStores.md#s2), [SA and SAO yields (S10)](../../knowledge/DataStores.md#s10) and [Bond holidays (S16)](../../knowledge/DataStores.md#s16), and produce the retrieved form of each:

- Read [Ref CPI (S3)](../../knowledge/DataStores.md#s3) and [TIPS reference data (S2)](../../knowledge/DataStores.md#s2) in full; either failing to load stops [Load market data (4.1)](/knowledge/DFD_LEVEL3_TLM_LOAD) entirely, since neither source is optional.
- Read [SA and SAO yields (S10)](../../knowledge/DataStores.md#s10), keeping only the [SA Yield](../../knowledge/DATA_DICTIONARY.md#sa-yield) column — the ask and SAO yield columns are parsed but not used here.
- Read [Bond holidays (S16)](../../knowledge/DataStores.md#s16), on a three-second timeout.
  - If it cannot be read in time: produce an empty [Bond Holidays](../../knowledge/DATA_DICTIONARY.md#bond-holiday) set — a settlement-date calculation then falls back to skipping weekends alone.

**Output:** [TIPS reference data](../../knowledge/DataStores.md#s2) and [Bond Holidays](../../knowledge/DATA_DICTIONARY.md#bond-holiday), to [Fetch and parse market quotes (4.1.1)](#fetch-and-parse-market-quotes); [Bond Holidays](../../knowledge/DATA_DICTIONARY.md#bond-holiday), also to the rest of the app directly, for coupon and payment-date rolling elsewhere; [SA Yield](../../knowledge/DATA_DICTIONARY.md#sa-yield), to [Build TIPS market data (4.1.4)](#build-tips-market-data); [Ref CPI](../../knowledge/DATA_DICTIONARY.md#ref-cpi), to the rest of the app directly, for Ref CPI lookups elsewhere.

<a id="build-tips-market-data"></a>
### 4.1.4 Build TIPS market data

**Implemented by:** `TipsLadderManager/src/rebalance-lib.js#buildTipsMapFromYields`

Read the [TIPS Yields](../../knowledge/DATA_DICTIONARY.md#tips-yields) that [Fetch and parse market quotes (4.1.1)](#fetch-and-parse-market-quotes) produced, and the [SA Yield](../../knowledge/DATA_DICTIONARY.md#sa-yield) that [Fetch auxiliary TIPS data (4.1.3)](#fetch-auxiliary-tips-data) produced, and produce [TIPS Market Data](../../knowledge/DATA_DICTIONARY.md#tips-market-data):

- For each TIPS: keep its CUSIP, [Maturity Date](../../knowledge/DATA_DICTIONARY.md#maturity-date), [Coupon Rate](../../knowledge/DATA_DICTIONARY.md#coupon-rate), dated date [Ref CPI](../../knowledge/DATA_DICTIONARY.md#ref-cpi), [Price](../../knowledge/DATA_DICTIONARY.md#price) and [Yield](../../knowledge/DATA_DICTIONARY.md#yield) unchanged, and attach its [SA Yield](../../knowledge/DATA_DICTIONARY.md#sa-yield), or none where [SA and SAO yields (S10)](../../knowledge/DataStores.md#s10) has no entry for that CUSIP.

The app's own "Mkt" tab (the TIPS Ref/Mkt popup, `TipsLadderManager/index.html#_showTipsRefModal`) displays this table directly, titled "TIPS Mkt Data", adding an Index Ratio and Adjusted Price computed at display time from the currently selected Ref CPI date.

**Output:** [TIPS Market Data](../../knowledge/DATA_DICTIONARY.md#tips-market-data), to [Import holdings and DARA plan (4.2)](/knowledge/DFD_LEVEL3_TLM_IMPORT), [Build ladder (4.3)](/knowledge/DFD_LEVEL2_TIPSLADDERMANAGER) and [Rebalance ladder (4.4)](/knowledge/DFD_LEVEL2_TIPSLADDERMANAGER).
