## Ladder CSV

The **Ladder CSV** option is enabled after a run completes for the current mode. It writes `tips-ladder-<mode>-YYYY-MM-DD.csv` (`_exportLadderCsv`, `index.html`), where `<mode>` is `build` or `rebalance`.

- The header row holds the label of every column of the table of the current mode ([4.5.1 §COLS Schema](./4.5.1_Render_Ladder_Table.md#cols-schema)), with *Quantity* written as *Qty*, followed by the columns *Principal per TIPS*, *Last Cpn Per TIPS*, *LMI*, *Cost per TIPS*, *Annual Int per TIPS*, *Int from excess* and *PLI*. The first of these seven columns has an empty label and an empty value in every row.
- One row is written per detail row of the run. A row with Excess TIPS is followed by a second row with the excess figures of the table columns.
- Every cell is quoted. A quantity is written as a whole number, a yield in percent, and any other number unrounded.
