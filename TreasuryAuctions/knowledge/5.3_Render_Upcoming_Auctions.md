# 5.3 Render Upcoming Auctions

**Specifies:** [5.3 Render Upcoming Auctions](/knowledge/DFD_LEVEL2_TREASURYAUCTIONS)
**Implemented by:** `TreasuryAuctions/src/app.js` (`renderUpcoming`, `showUpcomingCount`), `TreasuryAuctions/index.html`
**Input:** [Upcoming Auctions](../../knowledge/DATA_DICTIONARY.md#upcoming-auctions), [Auction Results](../../knowledge/DATA_DICTIONARY.md#auction-results) and the [Tentative Auction Schedule](../../knowledge/DATA_DICTIONARY.md#tentative-auction-schedule), from [Load auction data (5.1)](./5.1_Load_Auction_Data.md)
**Output:** [Charts and Tables](../../knowledge/DATA_DICTIONARY.md#charts-and-tables) to the user

Draw the Upcoming Auctions tab from the [Upcoming Auctions](../../knowledge/DATA_DICTIONARY.md#upcoming-auctions), flagging each TIPS auction with the [Auction results (S5)](../../knowledge/DATA_DICTIONARY.md#s5) rows and the [Tentative auction schedule (S9)](../../knowledge/DATA_DICTIONARY.md#s9) rows.

<a id="upcoming-auctions"></a>

- Show one row for each upcoming auction, in the order the feed states, with the columns CUSIP, Announced, Auction Date, Issue Date, Term, Type, Reopen and TIPS. Show the dates as mm/dd/yyyy. This tab has no filter row and no sort.
- State the number of rows followed by " upcoming auctions" in the tab bar, only while the Upcoming Auctions tab is active. The message rows below are not counted.
- Set TIPS to "Yes", in bold green, when any of these holds, and to "No" otherwise:
  - The Type contains the text "TIPS", in any case.
  - [Tentative auction schedule (S9)](../../knowledge/DATA_DICTIONARY.md#s9) has a row with the same auction date and the same Term, in any case, whose TIPS flag is "Yes".
  - The CUSIP is the CUSIP of an [Auction results (S5)](../../knowledge/DATA_DICTIONARY.md#s5) row whose `inflation_protected` is `Yes`. This identifies a reopened TIPS, which FiscalData states with its remaining term (9-Year 10-Month for a reopened 10-Year TIPS) and which the Term of S9 does not match. Measured 2026-10-17, all 160 reopened TIPS auctions in S5 carry the CUSIP of an earlier TIPS auction.
- When the upcoming auctions did not load, the tab reads "No upcoming auction data available."; when they loaded with no rows it reads "No upcoming auctions found."
- When S9 has no rows, no upcoming auction is flagged TIPS by the schedule.
