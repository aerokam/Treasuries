# 10.4 Render deck pages

**Specifies:** [10.4 Render deck pages](/knowledge/DFD_LEVEL2_PRIMER)
**Implemented by:** `Primer/index.html`, `Primer/src/deck-manager.js` (`renderBlocks`)
**Input:** [Deck Pages](../../knowledge/DATA_DICTIONARY.md#deck-pages) from [Load deck (10.1)](./10.1_Load_Deck.md); [View Selections](../../knowledge/DATA_DICTIONARY.md#view-selections) from the user (the page selected)
**Output:** [Charts and Tables](../../knowledge/DATA_DICTIONARY.md#charts-and-tables) to the user

Draw one page of the deck at a time, with its table of contents.

<a id="render-deck-pages"></a>
- Build one page for each page of the deck, with its chapter and title above its content. Build the table of contents from the chapters and titles, and one dot for each page.
- Show the page the user selects with the Prev and Next buttons, a click on a dot, an entry of the table of contents, or the left and right arrow keys. The arrow keys do nothing while the table of contents is open, which the Escape key closes, or while the focus is in an input, a select or a text area. State the chapter and "n/N" in the crumb.
- Draw the blocks of a page when it is shown, by block type: a definition card, a list card, a card table, and the lead, example, callout and aside blocks and the table.
- When the page has a calculator, mount it after the blocks with [Run calculators (10.3)](./10.3_Run_Calculators.md). While the market data of [Load market data (10.2)](./10.2_Load_Market_Data.md) has not arrived, the page states "Loading live data…".
- When a page cannot be drawn, state "Error rendering this page: " and the reason.
