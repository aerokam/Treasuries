# 12.1 Load OID inputs

**Specifies:** the OID Calculator of [Taxation of Treasuries](../index.html)
**Implemented by:** `TaxationOfTreasuries/src/oid-calculator.js` (`loadInputs`), `shared/src/market-data.js` (`fetchTipsRefRows`, `fetchRefCpiRows`)
**Input:** [TIPS reference data (S2)](../../knowledge/DATA_DICTIONARY.md#s2) and [Ref CPI (S3)](../../knowledge/DATA_DICTIONARY.md#s3)

Read the two stores the OID calculation needs. [Fetch TIPS reference data (1.6)](../../knowledge/1.6_Fetch_TIPS_Reference_Data.md) writes S2 and [Fetch daily Ref CPI (1.13)](../../knowledge/1.13_Fetch_Daily_Ref_CPI.md) writes S3.

<a id="data"></a>
When the OID Calculator is opened in the left pane, fetch both stores in parallel and build the rows:

- Read S2 with `fetchTipsRefRows()` as one row per TIPS of `cusip`, `maturity`, `datedDate`, `coupon` and `datedDateRefCpi`. Drop a row whose `datedDateRefCpi` is not a number.
- Read S3 with `fetchRefCpiRows()` as one row per calendar day, oldest first, of `date` and `refCpi`. S3 runs past the current date, because Treasury publishes the Ref CPI several weeks ahead.
- Show the status "Ref CPI from " and the first date of S3, " through " and the last date of S3.
- When either fetch fails, show the status "Load error: " and the reason, in red, and calculate nothing.
