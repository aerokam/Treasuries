# 12.2 Calculate TIPS OID

**Specifies:** the OID Calculator of [Taxation of Treasuries](../index.html)
**Implemented by:** `shared/src/tips-oid.js` (`calculateTipsOid`), `shared/src/ref-cpi.js` (`lookupRefCpi`, `indexRatio`, `roundHalfUp`)
**Input:** the rows of [Load OID inputs (12.1)](./12.1_Load_Oid_Inputs.md); the CUSIP, [Quantity](../../knowledge/DATA_DICTIONARY.md#quantity), [Start Date](../../knowledge/DATA_DICTIONARY.md#start-date), [End Date](../../knowledge/DATA_DICTIONARY.md#end-date) and Index Ratio rounding from the user

Calculate the [OID](../../knowledge/DATA_DICTIONARY.md#oid) of one TIPS from a Start Date to an End Date.

<a id="oid"></a>
## OID

- Take the TIPS as the row of S2 whose `cusip` is the CUSIP.
- Set [Par](../../knowledge/DATA_DICTIONARY.md#par) to the Quantity × $1,000.
- Look up the [Ref CPI](../../knowledge/DATA_DICTIONARY.md#ref-cpi) of the Start Date and of the End Date by the exact date, with `lookupRefCpi`.
- Set the [Index Ratio](../../knowledge/DATA_DICTIONARY.md#index-ratio) of each date to its Ref CPI divided by the Dated Date Ref CPI of the TIPS, with `indexRatio`. The user selects one of two roundings for both dates:
  - Not rounded: the ratio as the division gives it.
  - Rounded as Treasury rounds it: truncated to six decimal places and then rounded to five, as [31 CFR 356 Appendix B](../../knowledge/31_CFR_356_Definitions_And_Formulas.md) states for the payments Treasury calculates.
- Set OID to Par × (Index Ratio of the End Date − Index Ratio of the Start Date), rounded to cents. A negative OID is a deflation adjustment.

The calculation uses the dates as entered and applies no rule that selects them. The [Start Date](../../knowledge/DATA_DICTIONARY.md#start-date) and [End Date](../../knowledge/DATA_DICTIONARY.md#end-date) entries state which date each case enters.

<a id="latest-ref-cpi"></a>
## End Date after the last Ref CPI

- When the End Date is after the last date of S3, calculate the OID at the last date of S3. The result states that date and that it replaces the End Date.
- When the Start Date is after the last date of S3, there is no result.

<a id="invalid"></a>
## Inputs with no result

The calculation returns a reason, and [Render OID calculator (12.3)](./12.3_Render_Oid_Calculator.md) states it, when:

- no row of S2 has the CUSIP;
- the Quantity is not a whole number of 1 or more;
- a date is missing;
- the Start Date is after the End Date;
- the Start Date is before the [Dated Date](../../knowledge/DATA_DICTIONARY.md#dated-date) of the TIPS, or after its [Maturity Date](../../knowledge/DATA_DICTIONARY.md#maturity-date);
- the End Date is after the Maturity Date;
- S3 has no Ref CPI for the Start Date, or for an End Date inside the range of S3.
