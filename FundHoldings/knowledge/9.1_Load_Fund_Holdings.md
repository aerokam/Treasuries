# 9.1 Load fund holdings

**Specifies:** [9.1 Load fund holdings](/knowledge/DFD_LEVEL2_FUNDHOLDINGS)
**Implemented by:** `FundHoldings/index.html` (`loadFund`, `renderTabs`), `shared/src/csv.js`
**Input:** the file of the selected fund in [Fund holdings (S11)](../../knowledge/DATA_DICTIONARY.md#s11); [View Selections](../../knowledge/DATA_DICTIONARY.md#view-selections) from the user

Read the file of the selected fund from S11 and state the fund above the table. [Enrich fund holdings (1.14)](../../knowledge/1.14_Enrich_Fund_Holdings.md) writes the file.

- Draw one tab for each ticker, in the order VBIL, XHLF, ICPI, RBIL, VTIP, SCHP, VTP, LTPZ, starting on VBIL.
- Load `<TICKER>.csv` from R2 with the cache bypassed when the page opens, for VBIL, and at each click on a tab, for that ticker.
- When the file is missing the page reads "No data for " and the ticker, and when it has no holdings "no holdings rows."
- Read the file by its [File Layout](../../knowledge/1.14_Enrich_Fund_Holdings.md#file-layout): the metadata rows, the table header, one row per holding and the Total / Wtd Avg row.
- State above the table: the ticker and fund name, "Expense Ratio" and "30-Day SEC Yield" each to 2 decimal places when the file has them, and the number of holdings with the as-of date.
