# 1.0 Fund Holdings

**Implemented by:** `FundHoldings/index.html`, `FundHoldings/enrichHoldings.js`, `FundHoldings/updateAllHoldings.js`, `shared/src/bond-math.js` (`calculateDuration`, `termYears`, `calcMktWtdAvg`), `shared/src/csv.js`, `shared/upload.js`

Show the holdings of eight Treasury and TIPS funds, one tab for each, by CUSIP, with each holding's yield, term and duration and the fund's weighted averages. [Fund holdings (S11)](../../knowledge/DATA_DICTIONARY.md#s11) holds each fund's file, and the page reads it directly from R2. [Enrich fund holdings (1.14)](../../knowledge/1.14_Enrich_Fund_Holdings.md) writes it.

<a id="file-layout"></a>
## File Layout: `FundHoldings/<TICKER>.csv`

`enrichHoldings.js#buildFundCsv` writes three parts to one file:

- **Metadata**: a header row and one data row, aligned to the columns of the table below it:
  - `Ticker` (under CUSIP), `Fund Name` (under Description), `As of` (under Maturity Date), `Expense Ratio` (under Coupon), a blank cell (under % of Fund), `Holdings` (under Market Value) and `30-Day SEC Yield` (under Ask Yield).
  - `Expense Ratio` and `30-Day SEC Yield` are the provider's figures from `FundMeta.json`, written with a % sign. `As of` is the as-of date of the first holding, written `YYYY-MM-DD`. `Holdings` is the number of holdings.
- **Table**: a header row and one row per holding, with the columns `CUSIP`, `Description`, `Maturity Date`, `Coupon`, `% of Fund`, `Market Value`, `Ask Yield`, `SA Yield`, `SAO Yield`, `Term (w)` or `Term (y)`, and `Duration (y)`.
  - Write `SA Yield` and `SAO Yield` only when at least one holding has an SA Yield. A fund of nominal Treasuries has neither.
  - `Description` is the `Holding Name` of the raw file. `ISIN`, `SEDOL`, `Ticker`, `Category` and `Quantity` are not written.
  - Write `Coupon` and `% of Fund` with a % sign as percent values (6.75 is 6.75%), and `Ask Yield`, `SA Yield` and `SAO Yield` with a % sign as the yield times 100.
- **Total row**: no header row. It has `Total / Wtd Avg` in `Description`, the sums of `% of Fund` and `Market Value`, and the weighted averages of `Coupon`, `Ask Yield`, `SA Yield`, `SAO Yield`, `Term` and `Duration` ([Enrichment Logic](#enrichment-logic)). CUSIP and Maturity Date are blank.
- Round every number to 15 significant figures. The file is data, so values are not rounded for display.

<a id="enrichment-logic"></a>
## Enrichment Logic

**Implemented by:** `FundHoldings/enrichHoldings.js` (`enrichRow`, `buildFundCsv`)

For each holding of the raw file, by CUSIP, with the run date as the settlement date:

- Read [SA and SAO yields (S10)](../../knowledge/DATA_DICTIONARY.md#s10) and the Treasury rows of [Market quotes (S7)](../../knowledge/DATA_DICTIONARY.md#s7), those whose `Product` is not `TIPS`.
- Treat a holding as a TIPS when its CUSIP is in S10, and as a nominal Treasury when its CUSIP is in those S7 rows.
  - For a TIPS, set Ask Yield, SA Yield, SAO Yield and Coupon from the S10 row.
  - For a nominal Treasury, set Ask Yield to its `Ask yield to maturity` divided by 100 and Coupon from the S7 row, and leave SA Yield and SAO Yield blank.
  - For a holding in neither, leave Ask Yield and Coupon blank. This covers cash lines and a Treasury that S7 has no row for.
  - Replace the Coupon of the raw file with the Coupon of the matched row, because a provider can round it (ICPI states 0.13 for a 0.125% coupon).
- Set Term to the [Term](../../knowledge/DATA_DICTIONARY.md#term) from the run date to the Maturity Date, when the Maturity Date is after the run date. The run date, and not the as-of date of the holdings, anchors Term and Duration. A holding that matured after the as-of date and before the run date has no Term and no Duration.
- Set Duration to the [Duration](../../knowledge/DATA_DICTIONARY.md#duration) from the run date, calculated from the Coupon and the Ask Yield, when the Maturity Date is after the run date and both are present.
  - For a holding with no match whose `Holding Name` contains the word "bill" in any case, set Duration to its Term. A zero-coupon security has a Duration equal to its Term.
- Treat `MKTLIQ` (Vanguard) and `SSC GOVERNMENT MM GVMXX` (PIMCO and Schwab) as cash sweeps: blank their Maturity Date, because the provider states a date far in the future, and set their Term to one day.

<a id="total-row"></a>
**Total / Wtd Avg row**: weight by Market Value with `calcMktWtdAvg`, over two sets of holdings:

- Yield group (Coupon, Ask Yield, SA Yield, SAO Yield): the holdings that have an Ask Yield.
- Term and Duration: every holding with a Maturity Date and a value for the column, whether or not it has an Ask Yield. A cash line has no Maturity Date and is in neither set.
- Sum `% of Fund` (rounded to 8 decimal places) and `Market Value` over every holding.

**Term unit**: write the header `Term (w)` and the Terms in weeks when every holding with a Term has a Term under one year, and `Term (y)` in years otherwise. A week is 365.25 / 7 days.

<a id="display"></a>
## Display

**Implemented by:** `FundHoldings/index.html`

- Draw one tab for each ticker, in the order VBIL, XHLF, ICPI, RBIL, VTIP, SCHP, VTP, LTPZ, starting on VBIL. A tab loads `<TICKER>.csv` from R2 with the cache bypassed. When the file is missing the page reads "No data for " and the ticker, and when it has no holdings "no holdings rows."
- State above the table: the ticker and fund name, "Expense Ratio" and "30-Day SEC Yield" each to 2 decimal places when the file has them, and the number of holdings with the as-of date.
- Draw the columns the table header of the file states. `SA Yield` and `SAO Yield` appear only when the file has them. The header reads `Term (w)` or `Term (y)` as the file does, and `Duration (y)`.
- Format the cells: Market Value as a whole number with thousands separators, % of Fund and the three yields to 2 decimal places with a % sign, Coupon to 3 decimal places with a % sign, Term and Duration to 2 decimal places. A blank value stays blank.
- Show the Total / Wtd Avg row of the file as the footer, as the file states it.
- Strip a trailing coupon and date, such as ` 0.125% 10/15/2026`, from the Description for display. fminvest.com holding names carry it.
- Sort a column other than CUSIP and Description by a click on its header: ascending first, and descending on the next click. Place blank values last in either direction. The sort carries over to the next tab.
- Resize a column by dragging the right edge of its header, down to 40 px. Sizes are kept for the page session.
