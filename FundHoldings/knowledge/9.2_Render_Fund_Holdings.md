# 9.2 Render fund holdings

**Specifies:** [9.2 Render fund holdings](/knowledge/DFD_LEVEL2_FUNDHOLDINGS)
**Implemented by:** `FundHoldings/index.html` (`renderTable`, `sortRows`, `fmt`, `headerLabel`, `displayName`)
**Input:** [Fund Holdings](../../knowledge/DATA_DICTIONARY.md#fund-holdings) from [Load fund holdings (9.1)](./9.1_Load_Fund_Holdings.md); [View Selections](../../knowledge/DATA_DICTIONARY.md#view-selections) from the user
**Output:** [Charts and Tables](../../knowledge/DATA_DICTIONARY.md#charts-and-tables) to the user

Draw the holdings of the selected fund as a table.

- Draw the columns the table header of the file states. `SA Yield` and `SAO Yield` appear only when the file has them. The header reads `Term (w)` or `Term (y)` as the file does, and `Duration (y)`.
- Format the cells: Market Value as a whole number with thousands separators, % of Fund and the three yields to 2 decimal places with a % sign, Coupon to 3 decimal places with a % sign, Term and Duration to 2 decimal places. A blank value stays blank.
- Show the Total / Wtd Avg row of the file as the footer, as the file states it.
- Strip a trailing coupon and date, such as ` 0.125% 10/15/2026`, from the Description for display. fminvest.com holding names carry it.
- Sort a column other than CUSIP and Description by a click on its header: ascending first, and descending on the next click. Place blank values last in either direction. The sort carries over to the next tab.
- Resize a column by dragging the right edge of its header, down to 40 px. Sizes are kept for the page session.
