# 2.3 Calculate day change

**Specifies:** [2.3 Calculate day change](/knowledge/DFD_LEVEL2_YIELDSMONITOR)
**Implemented by:** `YieldsMonitor/src/app.js#updateCharts` (the closeP walk)
**Input:** [Yield Series](../../knowledge/DATA_DICTIONARY.md#yield-series) and its own underlying raw feed caches, from [Assemble range data (2.1)](./2.1_Assemble_Range_Data.md); [Live Quotes](../../knowledge/DATA_DICTIONARY.md#live-quotes), from [Read live quotes (2.2)](./2.2_Read_Live_Quotes.md); [Bond Holiday](../../knowledge/DATA_DICTIONARY.md#bond-holiday), from [Bond holidays (S16)](../../knowledge/DataStores.md#s16)
**Output:** the current [Yield](../../knowledge/DATA_DICTIONARY.md#yield) and the [Day Change](../../knowledge/DATA_DICTIONARY.md#day-change) per symbol, to [Render time series (2.5)](./2.5_Render_Time_Series.md)

For every symbol, calculates the [Day Change](../../knowledge/DATA_DICTIONARY.md#day-change) shown next to it in the sidebar: the current [Yield](../../knowledge/DATA_DICTIONARY.md#yield) less the prior trading day's close.

## Dependencies

- [DATA_DICTIONARY.md](../../knowledge/DATA_DICTIONARY.md) — [Day Change](../../knowledge/DATA_DICTIONARY.md#day-change), [Yield](../../knowledge/DATA_DICTIONARY.md#yield), [Bond Holiday](../../knowledge/DATA_DICTIONARY.md#bond-holiday)
- [Close Price Investigation](./Close_Price_Investigation.md) — the evidence behind the 17:05 ET session-close reference this calculation walks back to
- [2.1 Assemble range data](./2.1_Assemble_Range_Data.md), [2.2 Read live quotes](./2.2_Read_Live_Quotes.md) — supply the readings this calculation subtracts
- [2.5 Render time series](./2.5_Render_Time_Series.md) — draws the result

---

<a id="calculate-day-change"></a>
For each symbol:

- Determine the current Yield: [Read live quotes (2.2)](./2.2_Read_Live_Quotes.md)'s own reading for this symbol, or, if that reading is unavailable, the last point of whichever raw feed cache [Assemble range data (2.1)](./2.1_Assemble_Range_Data.md) most recently populated for it.
  - If neither is available, no Day Change is shown for this symbol.
- Find the prior close, by walking backward through the widest raw feed cache 2.1 has populated for this symbol — the roughly ten-day `5D`-range cache in preference to the roughly two-day `1D`-range cache, falling back to the assembled [Yield Series](../../knowledge/DATA_DICTIONARY.md#yield-series) itself only if neither cache exists yet.
  - The `1D`-range cache is a rolling window that can slide forward far enough — observed over a weekend — to no longer contain the previous trading day's actual daytime session, only its overnight tail. A walk restricted to it in that state finds no qualifying point, falls through to the Previous Day Closing figure below, and on a weekend that figure can equal the current quote itself, since both reflect the same last trade — producing a change of exactly zero for every symbol. The wider cache reliably still contains the prior day's real close.
  - Before walking, drop every point dated a Saturday, a Sunday, or a [Bond Holiday](../../knowledge/DATA_DICTIONARY.md#bond-holiday): there is never a real trading close on one, so a bar dated one is necessarily an artifact — CNBC appends a trailing live-quote tick beyond the normal per-minute bars whose timestamp can be rolled forward to the current wall-clock day and time despite no trading having occurred. This is a calendar fact rather than a guess at the artifact's shape; two earlier attempts at detecting it by shape (a `%`-suffixed close value, then a bar-to-bar time-gap check) both proved fragile, because CNBC reformats an older tick's close to an ordinary numeric string, indistinguishable from a real bar, once a newer tick supersedes it.
  - Among what remains, find the most recent day, then scan backward for the last point on an earlier day timestamped 17:05 ET or earlier — the actual end-of-session consolidation close.
- Calculate the Day Change: the current Yield less that point's own Yield.
  - If no such point exists at all — the feed has nothing for the prior trading day, for instance while frozen during an outage — use [Read live quotes (2.2)](./2.2_Read_Live_Quotes.md)'s own Previous Day Closing figure instead: an official settlement-quote reference distinct from the 17:05 session-close reference used otherwise. The displayed reference states which one applies.
  - If neither is available, no Day Change is shown.

## Why this differs from CNBC's own displayed change

CNBC's own displayed day change uses a different reference: the Previous Day Closing field this process only falls back to, which reflects an official settlement-quote publication around mid-afternoon rather than the 17:05 ET session close this calculation walks back to first. A 2026-04-08 comparison on the 1-Year Treasury found the two references about 0.008 percentage points apart on that day. The discrepancy is expected: the two are stated against genuinely different points in the trading day, not competing measurements of the same one.

**Output:** the current Yield used, the Day Change, and the close reference it was calculated against, per symbol, to [Render time series (2.5)](./2.5_Render_Time_Series.md).
