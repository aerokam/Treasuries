# 2.2 Read live quotes

**Specifies:** [2.2 Read live quotes](/knowledge/DFD_LEVEL2_YIELDSMONITOR)
**Implemented by:** `YieldsMonitor/src/app.js#fetchLatestQuotes`, `#fetchTipsBondMeta`, `#resolveGroupLatest`
**Input:** [Live Quotes](../../knowledge/DATA_DICTIONARY.md#live-quotes), from [CNBC Quote Service (E15)](../../knowledge/DATA_DICTIONARY.md#e15)
**Output:** [Live Quotes](../../knowledge/DATA_DICTIONARY.md#live-quotes), to [Calculate day change (2.3)](./2.3_Calculate_Day_Change.md), [Adjust for seasonality (2.4)](./2.4_Adjust_For_Seasonality.md) and [Render time series (2.5)](./2.5_Render_Time_Series.md)

Reads every symbol's live reading from CNBC's REST quote service, a batched call independent of [Assemble range data (2.1)](./2.1_Assemble_Range_Data.md)'s own chart-bar feed. This is deliberate: the chart-bar feed can freeze or fall back to an archived day during a CNBC outage while the quote service keeps updating, so a [Yield](../../knowledge/DATA_DICTIONARY.md#yield) figure that must reflect the current market — the sidebar's own reading, a [Day Change](../../knowledge/DATA_DICTIONARY.md#day-change), the bond a Seasonally Adjusted overlay is calculated against — is read from here rather than from a chart's own last plotted point wherever that choice is available.

---

<a id="read-live-quotes"></a>
For every symbol the app tracks, in one batched request to CNBC's quote service:

- Read the live Yield, the time it was read, and the prior day's official closing Yield.
  - This is the reading [Calculate day change (2.3)](./2.3_Calculate_Day_Change.md) treats as the current Yield, and the one [Render time series (2.5)](./2.5_Render_Time_Series.md) shows in the sidebar next to each symbol — never a chart's own last plotted point, unless this reading is unavailable for that symbol.
- Resolve each symbol group's own freshness, for the "TIPS latest" / "Treasuries latest" sidebar labels:
  - TIPS: the time this reading was taken for the 10-Year TIPS, the group's reliable reference symbol.
  - Nominal Treasuries: the same, for the 10-Year Treasury.
  - TIPS and nominal Treasuries are tracked separately, not as one combined reading, because they can genuinely diverge in freshness — a CNBC outage has been observed affecting only the TIPS symbols while the nominal Treasuries stayed live, and a single combined label would either overclaim freshness for the group that is actually current or needlessly undersell the one that is not stale.
  - If this reading is unavailable for a group's reference symbol, its freshness label falls back to that symbol's own chart-bar feed's last-bar time instead.

For each of the five TIPS symbols eligible for a Seasonally Adjusted overlay, in a second request to the same service:

- Read the Maturity Date and Coupon Rate of the one real TIPS that symbol is quoting today.
  - CNBC's canonical-maturity symbols (`US1YTIPS`, `US2YTIPS`, and so on) are not synthetic constant-maturity indices: each is the bid Yield of one specific, real TIPS, and CNBC's own quote page identifies which one. This reading is authoritative for today only — the service exposes a symbol's current bond, not a historical mapping of which bond it quoted on a past date, which is why [Adjust for seasonality (2.4)](./2.4_Adjust_For_Seasonality.md) resolves every earlier date a different way.
  - Cached for the rest of the session and refreshed again only when the user asks for a refresh — unlike the first reading above, which is re-read on every data update.

**Output:** the live Yield, its time, the prior close, and (for the five TIPS symbols) today's bond identity, to [Calculate day change (2.3)](./2.3_Calculate_Day_Change.md), [Adjust for seasonality (2.4)](./2.4_Adjust_For_Seasonality.md) and [Render time series (2.5)](./2.5_Render_Time_Series.md).
