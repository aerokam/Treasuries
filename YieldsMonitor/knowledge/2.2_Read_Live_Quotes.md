# 2.2 Read live quotes

**Specifies:** [2.2 Read live quotes](/knowledge/DFD_LEVEL2_YIELDSMONITOR)
**Implemented by:** `YieldsMonitor/src/app.js#fetchLatestQuotes`, `#fetchTipsBondMeta`, `#resolveGroupLatest`
**Input:** [Live Quotes](../../knowledge/DATA_DICTIONARY.md#live-quotes), from [CNBC (E5)](../../knowledge/DATA_DICTIONARY.md#e5)'s quote service
**Output:** [Live Quotes](../../knowledge/DATA_DICTIONARY.md#live-quotes), to [Calculate day change (2.3)](./2.3_Calculate_Day_Change.md), [Adjust for seasonality (2.4)](./2.4_Adjust_For_Seasonality.md) and [Render time series (2.5)](./2.5_Render_Time_Series.md)

Read the [Live Quotes](../../knowledge/DATA_DICTIONARY.md#live-quotes) of [CNBC (E5)](../../knowledge/DATA_DICTIONARY.md#e5) for every symbol and write them with the latest quote time of each symbol group. The quote service is independent of the chart-bar feed that [Assemble range data (2.1)](./2.1_Assemble_Range_Data.md) reads: during a CNBC outage the chart-bar feed can stop updating or be replaced by an archived day while the quote service keeps updating.

## Dependencies

- [DATA_DICTIONARY.md](../../knowledge/DATA_DICTIONARY.md) — [Live Quotes](../../knowledge/DATA_DICTIONARY.md#live-quotes), [Yield](../../knowledge/DATA_DICTIONARY.md#yield), [Maturity Date](../../knowledge/DATA_DICTIONARY.md#maturity-date), [Coupon Rate](../../knowledge/DATA_DICTIONARY.md#coupon-rate)
- [Assemble range data (2.1)](./2.1_Assemble_Range_Data.md) — the Yield Series that supply the latest quote time of a symbol group when its reference symbol has no quote

---

<a id="read-live-quotes"></a>
On each data update, in one batched request to the quote service for every symbol:

- Read the latest [Yield](../../knowledge/DATA_DICTIONARY.md#yield), its quote time and the previous day's closing Yield of each symbol.
  - A symbol the response omits, or a request that fails, has no [Live Quotes](../../knowledge/DATA_DICTIONARY.md#live-quotes).
  - [Calculate day change (2.3)](./2.3_Calculate_Day_Change.md) uses the Yield as the current Yield, and [Render time series (2.5)](./2.5_Render_Time_Series.md) shows it in the sidebar next to each symbol. Each states what it uses for a symbol with no Live Quotes.
- Write the latest quote time of each symbol group, for the "TIPS latest" and "Treasuries latest" sidebar labels:
  - TIPS: the quote time of the 10-Year TIPS.
  - Nominal Treasuries: the quote time of the 10-Year Treasury.
  - If the reference symbol has no quote time, the latest of the last-point times of the Yield Series of the symbols in the group.
  - The two groups are written separately because their freshness can differ: a CNBC outage was observed to affect the TIPS symbols while the nominal Treasuries stayed current.

For the five TIPS symbols that have a Seasonally Adjusted overlay, in a second request to the quote service:

- Read the [Maturity Date](../../knowledge/DATA_DICTIONARY.md#maturity-date) and [Coupon Rate](../../knowledge/DATA_DICTIONARY.md#coupon-rate) of the TIPS that each symbol quotes on the current date.
  - Each symbol (`US1YTIPS`, `US2YTIPS` and so on) quotes the Yield of one TIPS, which the quote service identifies by Maturity Date and Coupon Rate. Measured on 2026-10-16: `US2YTIPS` quoted the TIPS maturing 2028-07-15 with Coupon Rate 0.75%.
  - The quote service gives the TIPS of the current date only, so [Adjust for seasonality (2.4)](./2.4_Adjust_For_Seasonality.md) resolves earlier dates another way.
  - The reading is made when the Seasonally Adjusted overlay is first shown and again on each Refresh while an overlay is shown. A symbol with no Maturity Date or no Coupon Rate in the response has no entry.
