# 2.7 Render breakeven inflation

**Specifies:** [2.7 Render breakeven inflation](/knowledge/DFD_LEVEL2_YIELDSMONITOR)
**Constrained by:** [Visual Standards](./Visual_Standards.md)
**Implemented by:** `YieldsMonitor/src/app.js#updateYieldCurves` (the breakeven build)
**Input:** [Yield Series](../../knowledge/DATA_DICTIONARY.md#yield-series), from [Assemble range data (2.1)](./2.1_Assemble_Range_Data.md); [SA Yield Series](../../knowledge/DATA_DICTIONARY.md#sa-yield-series), from [Adjust for seasonality (2.4)](./2.4_Adjust_For_Seasonality.md)
**Output:** [Charts and Tables](../../knowledge/DATA_DICTIONARY.md#charts-and-tables), to the user

Draws the [Breakeven Inflation](../../knowledge/DATA_DICTIONARY.md#breakeven-inflation) curve, per security, for the five maturities this app tracks on both a nominal and a TIPS basis.

## Dependencies

- [Visual Standards](./Visual_Standards.md) — the pan and zoom rules this chart follows
- [DATA_DICTIONARY.md](../../knowledge/DATA_DICTIONARY.md) — [Breakeven Inflation](../../knowledge/DATA_DICTIONARY.md#breakeven-inflation), [Yield](../../knowledge/DATA_DICTIONARY.md#yield)
- [2.1 Assemble range data](./2.1_Assemble_Range_Data.md), [2.4 Adjust for seasonality](./2.4_Adjust_For_Seasonality.md) — supply every figure drawn here
- [2.6 Render yield curve snapshots](./2.6_Render_Yield_Curve_Snapshots.md) — shares this process's start and end dates and their label

---

## Per maturity pair

For each of the five pairs — 1-Year, 2-Year, 5-Year, 10-Year and 30-Year, each a nominal Treasury and a TIPS of the same stated maturity:

- Calculate the Breakeven: the nominal Treasury's Yield less the Yield of the TIPS, at the same date.

## Snapshot dates

Decided once, shared with [Render yield curve snapshots (2.6)](./2.6_Render_Yield_Curve_Snapshots.md) — see that process for the anchor symbol and its fallback:

- Start of Range: each pair's Breakeven calculated from the first available point of both series within the active range, or the picked Custom start date.
- Latest / End: the same, using the last available point.
- If either side of a pair has no point on the date in question, the pair is left a gap for that dataset rather than a partial or borrowed figure.
- Labeled with the same Eastern Time timestamp [Render yield curve snapshots (2.6)](./2.6_Render_Yield_Curve_Snapshots.md) uses, identical across all three curves.

## SA overlay

When the sidebar's Seasonally Adjusted toggle is on (see [Adjust for seasonality (2.4)](./2.4_Adjust_For_Seasonality.md)): two further datasets appear, each pair's nominal Yield less its SA TIPS Yield in place of the quoted one, from [Adjust for seasonality (2.4)](./2.4_Adjust_For_Seasonality.md)'s own series.

- A pair or date the rollover log cannot resolve is left a gap, drawn the same lighter-connector way [Render yield curve snapshots (2.6)](./2.6_Render_Yield_Curve_Snapshots.md) uses; the end point still resolves whenever the range's end date is today.
- Unchecking the Quoted toggle empties the raw Breakeven datasets, since every pair uses a TIPS Yield; the nominal side of the calculation is unaffected by either toggle on its own.
- Every dataset slot is always reserved, empty when a toggle is off, so a toggle updates the chart's data in place rather than rebuilding it.

**Output:** the Breakeven Inflation tab's chart, to the user.
