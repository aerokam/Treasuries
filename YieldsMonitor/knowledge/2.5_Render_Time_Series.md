# 2.5 Render time series

**Specifies:** [2.5 Render time series](/knowledge/DFD_LEVEL2_YIELDSMONITOR)
**Constrained by:** [Visual Standards](./Visual_Standards.md)
**Implemented by:** `YieldsMonitor/src/app.js#updateCharts`, `#createChartInstance`, `#updateDynamicTicks`, `#syncChartContainers`
**Input:** [Yield Series](../../knowledge/DATA_DICTIONARY.md#yield-series), from [Assemble range data (2.1)](./2.1_Assemble_Range_Data.md); [Live Quotes](../../knowledge/DATA_DICTIONARY.md#live-quotes), from [Read live quotes (2.2)](./2.2_Read_Live_Quotes.md); the current Yield and [Day Change](../../knowledge/DATA_DICTIONARY.md#day-change), from [Calculate day change (2.3)](./2.3_Calculate_Day_Change.md); [SA Yield Series](../../knowledge/DATA_DICTIONARY.md#sa-yield-series), from [Adjust for seasonality (2.4)](./2.4_Adjust_For_Seasonality.md)
**Output:** [Charts and Tables](../../knowledge/DATA_DICTIONARY.md#charts-and-tables), to the user

Draws one chart per checked symbol on the Time Series tab, and the sidebar readings next to every symbol regardless of whether it is checked.

## Dependencies

- [Visual Standards](./Visual_Standards.md) — the pan, zoom and rescale rules every chart here follows
- [DATA_DICTIONARY.md](../../knowledge/DATA_DICTIONARY.md) — [Yield](../../knowledge/DATA_DICTIONARY.md#yield), [Day Change](../../knowledge/DATA_DICTIONARY.md#day-change)

## Layout

Charts are grouped into a TIPS row and a Treasury row, each sorted by maturity. A chart appears only for a checked symbol; unchecking one removes its chart and re-flows the row.

## Sidebar symbol list

Every symbol shows its own reading regardless of whether it is checked — data is read for all symbols on every update, and only the charting area is gated on selection:

- Yield: the current Yield [Calculate day change (2.3)](./2.3_Calculate_Day_Change.md) resolved for that symbol.
- Day Change: 2.3's own result, colored by sign, with a tooltip stating the close reference it was calculated against.
- SA Yield: for the five TIPS symbols, today's reading from [Adjust for seasonality (2.4)](./2.4_Adjust_For_Seasonality.md)'s output series, shown with no further label since its column position and color already identify it.

## Time range selection

The sidebar offers preset range buttons — 2D, 10D, 1Y, 2Y, 3Y, 10Y, ALL — and a Custom option:

- A Custom range reveals a start-date and an end-date picker and an Apply button.
- Applying loads [Assemble range data (2.1)](./2.1_Assemble_Range_Data.md)'s Custom-range branch for the picked dates; the chart's own horizontal bounds are set to the picked window.

## X-axis tick density and labels

- 2D range: a fixed hourly unit; ticks labeled `MM/DD HH:mm` (e.g. `04/28 14:30`).
- 10D range: a fixed daily unit; ticks labeled `MMM D` (e.g. `Apr 28`).
- Every other range: the unit updates on every zoom or pan, at a threshold measured from the visible span rather than the preset range itself — hourly is never used again, daily below 90 days visible, monthly from 90 days up to about 18 months, yearly beyond that.
  - Below 90 days visible: ticks labeled `MMM D` (e.g. `May 1`).
  - From 90 days visible onward, at every coarser unit including the yearly one: ticks labeled `MMM YYYY` (e.g. `May 2025`) — the yearly unit widens the gap between ticks, it does not shorten the label to a bare year.
  - A tick whose label would repeat the previous tick's own label is left blank rather than shown twice.

## Intraday visual standards (2D and 10D ranges only)

- After-hours (before 08:00 and from 17:00 ET) is shaded on every trading day.
- A full Saturday or Sunday is shaded the same way, as one block.
- If a trading day's own data spans across 08:00 or 17:00 ET, a dashed vertical line marks whichever boundary it spans.
- The plotted line itself is drawn in a lighter shade of its color across any segment falling in after-hours or a weekend, to keep the primary trading session visually dominant.

None of this shading, boundary marking, or reduced-opacity segment applies outside 2D and 10D: every other range shows only the plain line.

## The stale-data bridge

When a symbol's live feed has fallen back to an archived day, or is otherwise frozen, while [Read live quotes (2.2)](./2.2_Read_Live_Quotes.md)'s own reading for that symbol is more than thirty minutes newer than the chart's own last plotted point:

- Draw a dashed horizontal line from that last point out to the current time, at the last point's own Yield level. The line is flat, not interpolated toward the live reading's own value, since no intraday data exists for that stretch — it marks elapsed time, not a real Yield path.
- Extend the chart's own default view out to the current time as well, rather than stopping just past the last real point, so the dashed bridge is visible without the user having to pan or zoom to find it.

This applies only to 2D and 10D, the two ranges with no other fallback once the live feed itself returns nothing (see [Assemble range data (2.1)](./2.1_Assemble_Range_Data.md)).

## SA overlay

For each of the five TIPS symbols: the raw (Quoted) Yield line is drawn first, the SA Yield line second, in a single distinguishing color rather than a dashed style, labeled "SA Yield" against "Yield" in the tooltip. Unchecking either "Quoted" or "SA" in the sidebar toggle (see [Adjust for seasonality (2.4)](./2.4_Adjust_For_Seasonality.md)) empties that chart's corresponding line rather than removing the chart; the Y-axis auto-rescale fits to whichever line or lines remain shown.

**Output:** the Time Series tab's charts and sidebar readings, to the user.
