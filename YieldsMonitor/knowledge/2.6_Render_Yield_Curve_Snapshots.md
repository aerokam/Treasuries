# 2.6 Render yield curve snapshots

**Specifies:** [2.6 Render yield curve snapshots](/knowledge/DFD_LEVEL2_YIELDSMONITOR)
**Constrained by:** [Visual Standards](./Visual_Standards.md)
**Implemented by:** `YieldsMonitor/src/app.js#updateYieldCurves`, `#valueOnDate`
**Input:** [Yield Series](../../knowledge/DATA_DICTIONARY.md#yield-series), from [Assemble range data (2.1)](./2.1_Assemble_Range_Data.md); [SA Yield Series](../../knowledge/DATA_DICTIONARY.md#sa-yield-series), from [Adjust for seasonality (2.4)](./2.4_Adjust_For_Seasonality.md)
**Output:** [Charts and Tables](../../knowledge/DATA_DICTIONARY.md#charts-and-tables), to the user

Draws two snapshot curves, TIPS and Nominal, comparing the shift and twist in Yields over the active range: every maturity's Yield read on the range's own start date against the same read on its end date.

## Dependencies

- [Visual Standards](./Visual_Standards.md) — the pan and zoom rules this chart follows
- [DATA_DICTIONARY.md](../../knowledge/DATA_DICTIONARY.md) — [Yield](../../knowledge/DATA_DICTIONARY.md#yield)
- [2.1 Assemble range data](./2.1_Assemble_Range_Data.md), [2.4 Adjust for seasonality](./2.4_Adjust_For_Seasonality.md) — supply every figure drawn here
- [2.7 Render breakeven inflation](./2.7_Render_Breakeven_Inflation.md) — shares this process's start and end dates and their label

---

## Snapshot dates

- Decide the start and end dates once, from a single anchor symbol, shared with [Render breakeven inflation (2.7)](./2.7_Render_Breakeven_Inflation.md) so all three curves compare the same two dates.
  - Anchor: 10-Year TIPS, whenever it has data for the active range.
  - If not: fall back through 1-Year TIPS, then 30-Year TIPS, then 2-Year TIPS, rather than leaving every curve blank for a range where only the primary anchor is missing.
  - 5-Year TIPS is never in this fallback list — its feed is too flaky to drive a date decision (see [Assemble range data (2.1)](./2.1_Assemble_Range_Data.md)).
  - [Assemble range data (2.1)](./2.1_Assemble_Range_Data.md) already clamps the anchor's own series to the active window, so its first and last points are the start and end dates directly, snapped past any non-trading day the window happens to begin or end on.
- If the Custom range is active: the picked start date snaps forward to the next date the anchor has data for, and the picked end date snaps backward the same way — a side effect of anchoring to the window-clamped series, not separate calendar logic.

## Per maturity

For each maturity, on the TIPS curve and on the Nominal curve:

- Read the Yield on the start date: that date's first point.
- Read the Yield on the end date: that date's last point.
- If a maturity has no point on the date in question, leave it a gap rather than borrowing a value from an adjacent date — this is why a flaky feed shows a gap instead of an out-of-window reading standing in for it.
  - The chart still draws a connecting line across the gap, in a lighter shade of the same color and dash than the rest of the line: a within-curve interpolation cue between two known neighbors, not a claim that the missing maturity's own value is known.

## Labeling

Both datasets are labeled with the Eastern Time timestamp of the anchor symbol's own point that fixed the date — identical across the TIPS curve, the Nominal curve, and the breakeven curve in [Render breakeven inflation (2.7)](./2.7_Render_Breakeven_Inflation.md).

## SA overlay

When the sidebar's Seasonally Adjusted toggle is on (see [Adjust for seasonality (2.4)](./2.4_Adjust_For_Seasonality.md)): the TIPS curve gains a Start and an End dataset, at all five TIPS maturities, read from [Adjust for seasonality (2.4)](./2.4_Adjust_For_Seasonality.md)'s own series on the same two dates as the raw curve.

- A maturity or date the rollover log cannot resolve is left a gap, drawn the same lighter-connector way as a raw-curve gap; the end point still resolves whenever the range's end date is today, since today's bond identity always comes from the live quote rather than the log.
- Unchecking the Quoted toggle empties the TIPS curve's own raw Start/End datasets, leaving only its SA datasets; the Nominal curve has no SA counterpart and is unaffected by either toggle.
- Both curves always reserve their dataset slots, empty when a toggle is off, so a toggle updates the chart's data in place rather than rebuilding it.

**Output:** the Yield Curves tab's chart, to the user.
