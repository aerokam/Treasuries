# 6.4 Export TIPS table

**Specifies:** [6.4 Export TIPS table](/knowledge/DFD_LEVEL2_TIPSREFERENCE)
**Implemented by:** `TipsReference/index.html` (the `export-btn` click handler)
**Input:** [TIPS Reference Rows](../../knowledge/DATA_DICTIONARY.md#tips-reference-rows) from [Render TIPS table (6.3)](./6.3_Render_TIPS_Table.md)
**Output:** [TIPS Reference Rows](../../knowledge/DATA_DICTIONARY.md#tips-reference-rows) to the user, as a csv file

Write the rows of the table to a csv file.

<a id="export"></a>
- Show the Export CSV button, disabled until the data loads.
- Write the rows the table shows, in its sort order, to `tips-reference-` and the Settlement Date, as `.csv`.
- Write the columns the table shows. Use the column labels as the header row and the values as displayed, with these exceptions: Adj Cpn/$1K and Adj Accrued/$1K are written to 6 decimal places, so that a holder multiplying either by a quantity rounds once, to the cent, on the total. A value that contains a comma is quoted.
