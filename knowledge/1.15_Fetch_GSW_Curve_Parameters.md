# 1.15 Fetch GSW curve parameters

**Specifies:** [1.15 Fetch GSW curve parameters](/knowledge/DFD_LEVEL2_INGESTION)  
**Implemented by:** `YieldCurves/scripts/updateGswTipsCurve.js`  
**Scheduled by:** `scripts/setup-windows-tasks.ps1`

Read the [GSW Curve Parameters](./DATA_DICTIONARY.md#gsw-curve-parameters) that [Federal Reserve FEDS 2008-05 (E13)](./DATA_DICTIONARY.md#e13) states, and write [GSW curve parameters (S12)](./DATA_DICTIONARY.md#s12):

- Read the table of recent Svensson fits that the Federal Reserve publishes, newest row first.
- Set the observation date and the `BETA0`–`BETA3`, `TAU1` and `TAU2` values to the values of the first row, as the source states them, unevaluated.

**Output:** [GSW curve parameters (S12)](./DATA_DICTIONARY.md#s12), read directly by YieldCurves as a reference line against its spot fit, drawn only on the analysis view opened with `?gsw`.
