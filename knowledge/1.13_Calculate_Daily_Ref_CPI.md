# 1.13 Calculate daily Ref CPI

**Specifies:** [1.13 Calculate daily Ref CPI](/knowledge/DFD_LEVEL3_INGEST_DAILYREFCPI)  
**Implemented by:** `scripts/calcDailyRefCpi.js`, `shared/src/ref-cpi.js#refCpiFromMonthly`  
**Scheduled by:** `scripts/syncCpiTasks.ps1`, with no standalone trigger: it chains from the `CpiHistory` task, after [1.12 Fetch CPI history](./1.12_Fetch_CPI_History.md) writes [CPI history (S8)](./DATA_DICTIONARY.md#s8)

Read [CPI history (S8)](./DATA_DICTIONARY.md#s8) and [Ref CPI (S3)](./DATA_DICTIONARY.md#s3), calculate the daily [Ref CPI](./DATA_DICTIONARY.md#ref-cpi) of the days after the last one S3 holds from the not-seasonally-adjusted series of S8, and write S3:

- Read the `NSA` value of each month of [CPI history (S8)](./DATA_DICTIONARY.md#s8).
  - A month with a blank `NSA`, which BLS did not report (October 2025), takes the number [31 CFR 356 Appendix B §I.B.4(iv)](./31_CFR_356_Definitions_And_Formulas.md) derives from the last available twelve-month change: `fillUnreportedMonths`. Treasury states 325.604 for October 2025, and Ref CPI from 2026-01-01 to 2026-01-31 rests on it.
- For each calendar day after the last date [Ref CPI (S3)](./DATA_DICTIONARY.md#s3) holds, or from 1997-01-15, the dated date of the first TIPS issued, when it holds none, calculate the Ref CPI as [1.10 Interpolate daily Ref CPI NSA and SA](./1.10_Interpolate_Daily_Ref_CPI_NSA_And_SA.md) does for the not-seasonally-adjusted series: the same `refCpiFromMonthly`, truncated to six decimal places and then rounded to five.
  - A day whose required month is not yet in [CPI history (S8)](./DATA_DICTIONARY.md#s8) has no value, and neither has any later day. The series therefore ends on the first of the month three months after the latest month of [CPI history (S8)](./DATA_DICTIONARY.md#s8), the day whose value is that latest month's `NSA` as it stands. With October 2026 the latest month, the series ends on 2027-01-01.
- Keep every date [Ref CPI (S3)](./DATA_DICTIONARY.md#s3) already holds with its value. Treasury continues to use the CPI as first reported when BLS later revises it ([31 CFR 356 Appendix B §I.B.4(i)](./31_CFR_356_Definitions_And_Formulas.md)), and [CPI history (S8)](./DATA_DICTIONARY.md#s8) states the revised value for 426 dates of March to November 2000 and July to November 2016 where the two differ.
- Write one row per calendar day, ascending by date.
- Write nothing and exit with a failure code when [CPI history (S8)](./DATA_DICTIONARY.md#s8) cannot be read, or when the merged series has a gap of more than one calendar day: [Ref CPI](./DATA_DICTIONARY.md#ref-cpi) is defined for every calendar day with no gap allowed.

[Ref CPI (S3)](./DATA_DICTIONARY.md#s3) is written at the time [CPI history (S8)](./DATA_DICTIONARY.md#s8) is, so it states each Ref CPI as soon as BLS has published the month it rests on, before [TreasuryDirect SecIndex (E2)](./DATA_DICTIONARY.md#e2) states it. [Check daily Ref CPI (1.17)](./1.17_Check_Daily_Ref_CPI.md) compares it with [TreasuryDirect SecIndex (E2)](./DATA_DICTIONARY.md#e2) once that source has published.
