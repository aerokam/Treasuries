## Scope

Reads the [Market Yields](./DATA_DICTIONARY.md#market-yields) that [CNBC (E5)](./DATA_DICTIONARY.md#e5)'s chart-bar feed states, for each of the fourteen symbols [Yield history (S6)](./DataStores.md#s6) tracks, and writes [Yield history (S6)](./DataStores.md#s6): one daily closing value per completed trading day per symbol, rewriting the whole file each run.

- For each symbol:
  - For each of CNBC's `ALL`, `5Y`, `6M`, `3M` and `1M` chart-bar feeds, coarsest first: merge each bar's date and value into the symbol's history already accumulated in [Yield history (S6)](./DataStores.md#s6), so a date already captured at a finer resolution is not coarsened again by a coarser feed that still covers it, while a fresher feed's value for a shared date overrides an earlier one.
    - Drop a bar dated on or after the current Eastern-time day: that day is still live and has not closed.
  - Stamp every retained date 15:00 Eastern, the time CNBC's daily-feed close tracks — the ~3 PM benchmark close, not the 17:05 session print (see [Close Price Investigation](../YieldsMonitor/knowledge/Close_Price_Investigation.md)).

**Output:** [Yield history (S6)](./DataStores.md#s6), to [2.1](../YieldsMonitor/knowledge/2.1_Assemble_Range_Data.md).
