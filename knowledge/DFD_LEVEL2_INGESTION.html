Level 2 — 1 Acquire and derive reference data

One process per scheduled job, with the external entity it reads (if any). The Data Stores shape stands for every data store: a job that writes one has an arrow to it, a job that reads one has an arrow from it, and a job that does both has both. 1.3, 1.10 and 1.11 read no external source: they calculate from what the retrieving jobs have stored. 1.1, 1.2, 1.4, 1.6, 1.7, 1.13 and 1.14 read both an external source and one or more stores. An entity feeding two jobs (FiscalData, BLS, CNBC) is drawn once, with a separately labelled flow to each — the same source, not two sources. FiscalData's two flows here match its two flows in the Data Dictionary; BLS's and CNBC's two jobs each read the same flow independently. 1.4 reads two entities, FiscalData and TreasuryDirect, for the one flow auction results. E7 through E12 are drawn as one box: the six fund-holdings providers, each with its own entry in the Data Dictionary, are otherwise identical in shape from this diagram's point of view — one job reads all six. Each job explodes at Level 3, which draws the data stores that job reads and writes and the shared modules it calls. 1.1 decomposes into three processes; every other job is one process there, and its bubble opens the job's process spec, which names the script that implements it and the script that registers its schedule.
