Level 2 — Yield Curves

No process here writes a data store. Every flow ends at 3.2 and is gone when the page closes. The three stores are written by Level 3 of 1.3 Calculate yield curve data sets, a scheduled job; the app calculates none of their values. Each flow is named by the one structure it holds, defined in Data Dictionary §6.0. Two structures passing between the same two processes are drawn as two flows. 3.1 also reads the GSW curve parameters, for a reference curve drawn only on an analysis view opened with ?gsw. No view of the app uses them otherwise, so they are not drawn here. The amber circles are shared modules (SharedModules.md), not process steps of this diagram.
