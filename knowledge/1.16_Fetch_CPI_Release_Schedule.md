# 1.16 Fetch CPI release schedule

**Specifies:** [1.16 Fetch CPI release schedule](/knowledge/DFD_LEVEL3_INGEST_CPIRELEASESCHEDULE)  
**Implemented by:** `scripts/fetchCpiReleaseSchedule.js`, `scripts/syncCpiTasks.ps1`  
**Scheduled by:** `scripts/setup-windows-tasks.ps1`

Read the [CPI Release Schedule](./DATA_DICTIONARY.md#cpi-release-schedule) that [BLS (E4)](./DATA_DICTIONARY.md#e4) states, and write [CPI release schedule (S19)](./DATA_DICTIONARY.md#s19):

- Read each row of the release table: `Reference Month`, `Release Date` and `Release Time`.
- Write `Release Date` as `YYYY-MM-DD`. `Reference Month` and `Release Time` are written as [BLS (E4)](./DATA_DICTIONARY.md#e4) states them.
- Sort the rows ascending by `Release Date`.
- Write nothing and exit with a failure code when the table is missing or has no rows, when a `Release Date` cannot be read, or when two rows have the same `Release Date`.
- Write one row per release, replacing the store's previous contents in full.
- Give [1.12 Fetch CPI history](./1.12_Fetch_CPI_History.md) one run at 08:35 Eastern and [1.13 Fetch daily Ref CPI](./1.13_Fetch_Daily_Ref_CPI.md) one run at 09:30 Eastern on each `Release Date` after the current date, and no other run.
