# 1.17 Check daily Ref CPI

**Specifies:** [1.17 Check daily Ref CPI](/knowledge/DFD_LEVEL3_INGEST_CHECKREFCPI)  
**Implemented by:** `scripts/checkDailyRefCpi.js`, `scripts/notify.js`  
**Scheduled by:** `scripts/syncCpiTasks.ps1`, run by [1.16 Fetch CPI release schedule](./1.16_Fetch_CPI_Release_Schedule.md), with one trigger on the day after each `Release Date` of [CPI release schedule (S19)](./DATA_DICTIONARY.md#s19)

Read the [Daily Ref CPI](./DATA_DICTIONARY.md#daily-ref-cpi) that [TreasuryDirect SecIndex (E2)](./DATA_DICTIONARY.md#e2) states for one outstanding TIPS, compare it with [RefCPI (S3)](./DATA_DICTIONARY.md#s3), and report the result. It writes no store:

- Skip the run when the day before the current date, on an Eastern clock, is not a `Release Date` of [CPI release schedule (S19)](./DATA_DICTIONARY.md#s19), checked before anything is fetched.
- End the run with an error and fetch nothing when [CPI release schedule (S19)](./DATA_DICTIONARY.md#s19) cannot be read.
- Read [TIPS reference data (S2)](./DATA_DICTIONARY.md#s2) and select the [Outstanding TIPS](./DATA_DICTIONARY.md#outstanding-tips) with the latest [Maturity Date](./DATA_DICTIONARY.md#maturity-date), the CUSIP that stays outstanding longest. The selection is repeated every run.
- Fetch that CUSIP's full daily series from [TreasuryDirect SecIndex (E2)](./DATA_DICTIONARY.md#e2), every calendar day it covers.
- Compare each fetched date with the `Ref CPI NSA` of the same date of [RefCPI (S3)](./DATA_DICTIONARY.md#s3). A date is a mismatch when [RefCPI (S3)](./DATA_DICTIONARY.md#s3) has no row for it or states a different value.
- Compare the last fetched date with the last day of the second month after the latest month of [CPI (S8)](./DATA_DICTIONARY.md#s8). A last fetched date before it means [TreasuryDirect SecIndex (E2)](./DATA_DICTIONARY.md#e2) has not yet published the range.

**The result is one of three, each written as a line to `logs/ref-cpi-check.log`:**

- *Match*: every fetched date agrees and the range is published. The line states the first and last dates compared.
- *Mismatch*: one or more fetched dates differ. The line states how many, and lists each with its [RefCPI (S3)](./DATA_DICTIONARY.md#s3) value and its [TreasuryDirect SecIndex (E2)](./DATA_DICTIONARY.md#e2) value.
- *Not yet published*: the last fetched date is before the end of the range. The line states that date and the date expected.

A mismatch and a not yet published result also show a Windows notification stating the result. A match shows none.

The run exits with a failure code on a mismatch or a not yet published result. It leaves [RefCPI (S3)](./DATA_DICTIONARY.md#s3) as it is in every case.
