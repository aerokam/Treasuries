# 1.18 Fetch CMT rates

*Status: Unbuilt — specified ahead of its code.*

**Specifies:** [1.18 Fetch CMT rates](/knowledge/DFD_LEVEL3_INGEST_CMTRATES)  
**Implemented by:** `YieldCurves/scripts/updateCmtRates.js`  
**Scheduled by:** `scripts/setup-windows-tasks.ps1`

Read the [CMT Rates](./DATA_DICTIONARY.md#cmt-rates) that [Treasury Par Yield Curve Rates (E16)](./DATA_DICTIONARY.md#e16) states, and write [CMT rates (S24)](./DATA_DICTIONARY.md#s24) and [R-CMT rates (S25)](./DATA_DICTIONARY.md#s25):

- For each series, the [CMT](./DATA_DICTIONARY.md#cmt) rates and the [R-CMT](./DATA_DICTIONARY.md#r-cmt) rates:
  - Read the store of the series.
  - Read the yearly file of the series from the year of the latest `Date` in the store through the current year. When the store is absent, read every yearly file from the first year of the series: 1990 for the CMT rates and 2003 for the R-CMT rates.
  - Set each `Date` to `YYYY-MM-DD`.
  - Set each rate to a decimal by moving the decimal point of the source's text two places to the left, so that 4.65 becomes `0.0465`. A blank cell stays blank.
  - Set the name of each maturity column to `n Mo` for a maturity of `n` months and `n Yr` for a maturity of `n` years. The source labels the unit `Mo`, `Month`, `Yr` or `YR`.
  - Merge the rows read into the stored rows by `Date`: a row read replaces the stored row of the same `Date`, and a stored row of another `Date` is kept.
  - End the series without a write when the merge changes no row.
  - Write the store, oldest `Date` first, with the columns of [CMT rates (S24)](./DATA_DICTIONARY.md#s24) or [R-CMT rates (S25)](./DATA_DICTIONARY.md#s25) in the order each entry states. A maturity that a yearly file has no column for is a blank cell. The write replaces the whole file.
- A series writes nothing, and the run ends with an error, when a yearly file cannot be read, when its header row has no `Date` column or has a maturity label that is not a column of the store, when a `Date` cannot be read, or when two rows share a `Date`. A failure in one series does not stop the other.
