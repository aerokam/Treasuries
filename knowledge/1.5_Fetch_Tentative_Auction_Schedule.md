## Scope

Reads the [Tentative Auction Schedule](./DATA_DICTIONARY.md#tentative-auction-schedule) XML that [Treasury Tentative Auction Schedule (E14)](./DATA_DICTIONARY.md#e14) publishes and writes it to [Tentative auction schedule (S9)](./DataStores.md#s9) unchanged, byte for byte — no row is added, dropped, or reshaped.

This mirror exists because a browser cannot fetch `home.treasury.gov` directly: the site sends no CORS header, so a browser `fetch()` from the TreasuryAuctions app is rejected regardless of origin. Running the fetch from a scheduled Windows task, outside the browser, has no such restriction.

**Output:** [Tentative auction schedule (S9)](./DataStores.md#s9), read directly by TreasuryAuctions.
