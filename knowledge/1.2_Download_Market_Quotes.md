# 1.2 Download market quotes

**Specifies:** [1.2 Download market quotes](/knowledge/DFD_LEVEL2_INGESTION)  
**Implemented by:** `YieldCurves/scripts/fidelityDownload.js`, `YieldCurves/scripts/uploadFidelityDownload.js`  
**Reference:** `knowledge/Data_Pipeline_Local.md` (gitignored — do not reference publicly per that file's own note)

## Dependencies

- [DATA_DICTIONARY.md](./DATA_DICTIONARY.md) — [Fidelity Fixed Income (E6)](./DATA_DICTIONARY.md#e6), [Bond Holiday](./DATA_DICTIONARY.md#bond-holiday), and the data flow [Market Quotes](./DATA_DICTIONARY.md#market-quotes)
- [DataStores.md](./DataStores.md) — [Market quotes (S7)](./DataStores.md#s7), and the bond holidays file
- `scripts/setup-windows-tasks.ps1` — the schedule of the Windows task that runs this process

---

Read [Fidelity Fixed Income (E6)](./DATA_DICTIONARY.md#e6) from the local downloads folder, and write [Market quotes (S7)](./DataStores.md#s7):

- Skip the run on a weekend or a [Bond Holiday](./DATA_DICTIONARY.md#bond-holiday), checked against [Bond holidays (S16)](./DataStores.md#s16) before the browser session that fetches [Fidelity Fixed Income (E6)](./DATA_DICTIONARY.md#e6) opens.
- Strip every `="value"` Excel literal-string wrapper the export applies to a field, to `value` — the only transformation applied.
- Leave every row, column and column order exactly as the export states them: no row is added, dropped, reordered or restructured.

**How [Fidelity Fixed Income (E6)](./DATA_DICTIONARY.md#e6) is obtained is out of scope for this spec.** The browser automation, sign-in and MFA steps are documented in the gitignored `knowledge/Data_Pipeline_Local.md`, which this spec links to and does not restate.

**A successful run chains into [Calculate SA and SAO yields (1.11)](./1.11_Calculate_SA_And_SAO_Yields.md).** A fresh [Market quotes (S7)](./DataStores.md#s7) is followed immediately by a fresh [SA and SAO yields (S10)](./DataStores.md#s10) built from it.

**Output:** [Market quotes (S7)](./DataStores.md#s7), to [Parse market quotes (3.1.2)](../YieldCurves/knowledge/3.1_Parse_Sources_And_Calculate_Yields.md#parse-market-quotes).
