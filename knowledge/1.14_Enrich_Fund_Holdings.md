# 1.14 Enrich fund holdings

**Specifies:** [1.14 Enrich fund holdings](/knowledge/DFD_LEVEL2_INGESTION)  
**Implemented by:** `FundHoldings/updateAllHoldings.js`, `FundHoldings/enrichHoldings.js`  
**Reference:** [FundHoldings 1.0 §Enrichment Logic](../FundHoldings/knowledge/1.0_FundHoldings.md#enrichment-logic)

## Dependencies

- [DATA_DICTIONARY.md](./DATA_DICTIONARY.md) — [Vanguard Advisors (E7)](./DATA_DICTIONARY.md#e7) through [BlackRock iShares (E12)](./DATA_DICTIONARY.md#e12), [Fund holdings (S11)](./DATA_DICTIONARY.md#s11), [Market quotes (S7)](./DATA_DICTIONARY.md#s7), [SA and SAO yields (S10)](./DATA_DICTIONARY.md#s10), and the data flow [Fund Holdings](./DATA_DICTIONARY.md#fund-holdings)
- [DataStores.md](./DataStores.md) — [Fund holdings (S11)](./DataStores.md#s11), [Market quotes (S7)](./DataStores.md#s7), [SA and SAO yields (S10)](./DataStores.md#s10)
- [FundHoldings/knowledge/1.0_FundHoldings.md](../FundHoldings/knowledge/1.0_FundHoldings.md) — the enrichment calculation itself, owned there since the app spec already states it in full
- `scripts/setup-windows-tasks.ps1` — the schedule of the Windows task that runs this process

---

Read the [Fund Holdings](./DATA_DICTIONARY.md#fund-holdings) that [Vanguard Advisors (E7)](./DATA_DICTIONARY.md#e7) through [BlackRock iShares (E12)](./DATA_DICTIONARY.md#e12) state, for the eight tracked fund tickers across the six providers, and write [Fund holdings (S11)](./DataStores.md#s11):

- For each of the six providers: fetch that provider's own holdings export for its ticker or tickers, independently of every other provider — a fetch failure here is caught and logged, and does not stop any other provider's fetch or any ticker's enrichment from proceeding.
- For each of the eight tickers, regardless of which providers just succeeded or failed: enrich that ticker's raw holdings CSV — see [FundHoldings 1.0 §Enrichment Logic](../FundHoldings/knowledge/1.0_FundHoldings.md#enrichment-logic) for the calculation itself — and write a raw and an enriched CSV to [Fund holdings (S11)](./DataStores.md#s11), the enriched file adding [Market quotes (S7)](./DataStores.md#s7)/[SA and SAO yields (S10)](./DataStores.md#s10)-derived yield, term and duration to every holding.
- Exit with a failure code, after every ticker has still been enriched and uploaded, if any provider's fetch failed — so the failure is visible in Windows Task Scheduler's run history, without withholding the tickers that did fetch successfully. No retry is configured for this task (`scripts/setup-windows-tasks.ps1`).

**Output:** [Fund holdings (S11)](./DataStores.md#s11), read directly by the Fund Holdings app.
