# 1.14 Enrich fund holdings

**Specifies:** [1.14 Enrich fund holdings](/knowledge/DFD_LEVEL2_INGESTION)  
**Implemented by:** `FundHoldings/updateAllHoldings.js`, `FundHoldings/enrichHoldings.js`  
**Scheduled by:** `scripts/setup-windows-tasks.ps1`  
**Reference:** [FundHoldings 1.0 §Enrichment Logic](../FundHoldings/knowledge/1.0_FundHoldings.md#enrichment-logic)

Read the [Fund Holdings](./DATA_DICTIONARY.md#fund-holdings) that [Vanguard Advisors (E7)](./DATA_DICTIONARY.md#e7) through [BlackRock iShares (E12)](./DATA_DICTIONARY.md#e12) state, for the eight tracked fund tickers across the six providers; enrich each ticker's holdings with a yield, term and duration derived from [Market quotes (S7)](./DATA_DICTIONARY.md#s7) and [SA and SAO yields (S10)](./DATA_DICTIONARY.md#s10); and write [Fund holdings (S11)](./DATA_DICTIONARY.md#s11):

- For each of the six providers: fetch that provider's own holdings export for its ticker or tickers, independently of every other provider — a fetch failure here is caught and logged, and does not stop any other provider's fetch or any ticker's enrichment from proceeding.
- For each of the eight tickers, regardless of which providers just succeeded or failed: enrich that ticker's local raw holdings CSV — see [FundHoldings 1.0 §Enrichment Logic](../FundHoldings/knowledge/1.0_FundHoldings.md#enrichment-logic) for the calculation itself, [§File Layout](../FundHoldings/knowledge/1.0_FundHoldings.md#file-layout) for the written file's structure — and write it to [Fund holdings (S11)](./DATA_DICTIONARY.md#s11).
- Exit with a failure code, after every ticker has still been enriched and uploaded, if any provider's fetch failed — so the failure is visible in Windows Task Scheduler's run history, without withholding the tickers that did fetch successfully. No retry is configured for this task (`scripts/setup-windows-tasks.ps1`).

**Output:** [Fund holdings (S11)](./DATA_DICTIONARY.md#s11), read directly by the Fund Holdings app.
