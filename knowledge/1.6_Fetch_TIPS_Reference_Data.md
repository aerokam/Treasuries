# 1.6 Fetch TIPS reference data

**Specifies:** [1.6 Fetch TIPS reference data](/knowledge/DFD_LEVEL2_INGESTION)  
**Implemented by:** `scripts/fetchTipsRef.js`, `shared/src/tips-ref.js`  
**Scheduled by:** `scripts/setup-windows-tasks.ps1`

Read the [TIPS Reference Data](./DATA_DICTIONARY.md#tips-reference-data) that [FiscalData (E3)](./DATA_DICTIONARY.md#e3) states, and write [TIPS reference data (S2)](./DATA_DICTIONARY.md#s2):

- Query the `treasury_securities_auctions_v2` table of FiscalData for a security whose `inflation_protected` field is `Yes` and whose `reopening` field is `No`, so a reopening of an existing TIPS contributes no second row.
- Set the CUSIP, the [Maturity Date](./DATA_DICTIONARY.md#maturity-date), the [Dated Date](./DATA_DICTIONARY.md#dated-date) and the term to the FiscalData fields of the same meaning, and the [Ref CPI](./DATA_DICTIONARY.md#ref-cpi) to the value FiscalData states in `ref_cpi_on_orig_dated_date`.
- Set the [Coupon Rate](./DATA_DICTIONARY.md#coupon-rate) to FiscalData's stated interest rate divided by 100, converting it from a percent to a decimal.
- Write a row only for a TIPS whose interest rate and Ref CPI FiscalData states. The table lists an auction when it is announced, with both null until the auction is held.
- Replace the row of the same CUSIP in the store with the new row, keep every other row of the store, and write the rows in order of Maturity Date. The table states only the auctions held since 2025-12-29, so the store's rows for earlier TIPS are kept.

**Output:** [TIPS reference data (S2)](./DATA_DICTIONARY.md#s2), to [Select prices and add TIPS reference data (1.1.2)](./1.1_Download_FedInvest_Prices.md#select-prices-and-add-tips-reference-data) and every other process that reads it directly ([Adjust for seasonality (2.4)](../YieldsMonitor/knowledge/2.4_Adjust_For_Seasonality.md)).
