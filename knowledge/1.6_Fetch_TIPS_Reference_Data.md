# 1.6 Fetch TIPS reference data

**Specifies:** [1.6 Fetch TIPS reference data](/knowledge/DFD_LEVEL2_INGESTION)  
**Implemented by:** `scripts/fetchTipsRef.js`

## Dependencies

- [DATA_DICTIONARY.md](./DATA_DICTIONARY.md) — [FiscalData (E3)](./DATA_DICTIONARY.md#e3), [TIPS reference data (S2)](./DATA_DICTIONARY.md#s2), [Ref CPI](./DATA_DICTIONARY.md#ref-cpi), [Dated Date](./DATA_DICTIONARY.md#dated-date), [Maturity Date](./DATA_DICTIONARY.md#maturity-date), [Coupon Rate](./DATA_DICTIONARY.md#coupon-rate), and the data flow [TIPS Reference Data](./DATA_DICTIONARY.md#tips-reference-data)

---

## Scope

Read the [TIPS Reference Data](./DATA_DICTIONARY.md#tips-reference-data) that [FiscalData (E3)](./DATA_DICTIONARY.md#e3) states, and write [TIPS reference data (S2)](./DataStores.md#s2): one row for every TIPS FiscalData has ever auctioned, replacing the store's previous contents in full — this is not a merge, unlike [Fetch auction results (1.4)](./1.4_Fetch_Auction_Results.md).

- Query FiscalData for a security whose `inflation_index_security` field is `Yes` and whose `reopening` field is `No`, so a reopening of an existing TIPS contributes no second row.
- Set the CUSIP, the [Maturity Date](./DATA_DICTIONARY.md#maturity-date), the [Dated Date](./DATA_DICTIONARY.md#dated-date) and the term to FiscalData's own fields of the same meaning, and the [Ref CPI](./DATA_DICTIONARY.md#ref-cpi) to the value FiscalData states on the dated date.
- Set the [Coupon Rate](./DATA_DICTIONARY.md#coupon-rate) to FiscalData's stated interest rate divided by 100, converting it from a percent to a decimal.

**Output:** [TIPS reference data (S2)](./DataStores.md#s2), to [Select prices and add TIPS reference data (1.1.2)](./1.1_Download_FedInvest_Prices.md#select-prices-and-add-tips-reference-data) and every other process that reads it directly ([Adjust for seasonality (2.4)](../YieldsMonitor/knowledge/2.4_Adjust_For_Seasonality.md)).
