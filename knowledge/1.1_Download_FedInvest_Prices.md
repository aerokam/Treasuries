## Processes

<a id="determine-settlement-date"></a>
### 1.1.1 Determine settlement date

**Implemented by:** `scripts/getYieldsFedInvest.js#determineSettlementDate`

Extract the `Prices For:` date from the [FedInvest (E1)](./DATA_DICTIONARY.md#e1) webpage, and pass it to [Calculate yields (1.1.3)](#calculate-yields) as the [Settlement Date](./DATA_DICTIONARY.md#settlement-date):

- If the run date, in Eastern time, is a [Bond Holiday](./DATA_DICTIONARY.md#bond-holiday): stop here, passing no [Settlement Date](./DATA_DICTIONARY.md#settlement-date) onward. Exit cleanly — no retry.
- Fetch the [FedInvest (E1)](./DATA_DICTIONARY.md#e1) webpage.
  - If its page text does not contain `Prices For:`: stop here, passing no [Settlement Date](./DATA_DICTIONARY.md#settlement-date) onward. Exit cleanly — no retry; the page has not published a price list for the run date yet.
- Extract the date following `Prices For:` in the page text, in whichever of two forms it appears: `YYYY Mon D` (for example `2026 Mar 23`) or `Mon D, YYYY` (for example `Mar 23, 2026`), `Mon` a three-letter month abbreviation.
  - If the page's price table has no rows despite stating this date: throw — an uncaught failure, restarted the same as the next case.
- If the extracted date is not the run date: stop here, passing no [Settlement Date](./DATA_DICTIONARY.md#settlement-date) onward, and exit with a failure code — FedInvest is still showing a prior day's price list. Windows Task Scheduler restarts the task every 10 minutes, up to 12 times (2 hours), on that failure code (`scripts/setup-windows-tasks.ps1`).
- Otherwise: pass the extracted date onward as the [Settlement Date](./DATA_DICTIONARY.md#settlement-date) itself (T+0) — unlike a market quote, which settles one bond trading day after its [Download Date](./DATA_DICTIONARY.md#download-date) (T+1, [Determine settlement date (3.1.6)](../YieldCurves/knowledge/3.1_Parse_Sources_And_Calculate_Yields.md#determine-settlement-date)).

**T+0 was determined empirically.** Yields calculated from FedInvest prices at T+0 come close to the yields of broker quotes settling at T+1. The developer established this in a spreadsheet comparison. No record of that measurement is held in this repository.

**Output:** the [Settlement Date](./DATA_DICTIONARY.md#settlement-date), to [Calculate yields (1.1.3)](#calculate-yields).

<a id="select-prices-and-add-tips-reference-data"></a>
### 1.1.2 Select prices and add TIPS reference data

**Implemented by:** `shared/src/fedinvest-prices.js#parseFedInvestPriceRows`, `shared/src/fedinvest-prices.js#selectPricedSecurity`

Read the rows of the [FedInvest (E1)](./DATA_DICTIONARY.md#e1) price table and [TIPS reference data (S2)](./DataStores.md#s2), and produce the [TIPS Prices](./DATA_DICTIONARY.md#tips-prices) and the [Treasury Prices](./DATA_DICTIONARY.md#treasury-prices):

- Recognize a line of the price table as a row when it starts with a 9-character CUSIP; its header and footer lines do not, and are not rows.
- Keep a row whose `SECURITY TYPE` is `TIPS`, `MARKET BASED BILL`, `MARKET BASED NOTE` or `MARKET BASED BOND`; drop every other row.
- Set the [Price](./DATA_DICTIONARY.md#price) to the `BUY` price, the `SELL` price where `BUY` is empty or zero, or the `END OF DAY` price where both are; a row with none of the three has no price.
- Set the [Coupon Rate](./DATA_DICTIONARY.md#coupon-rate) and the [Maturity Date](./DATA_DICTIONARY.md#maturity-date):
  - For a TIPS: to the values, and the dated date [Ref CPI](./DATA_DICTIONARY.md#ref-cpi), that [TIPS reference data (S2)](./DataStores.md#s2) holds for its CUSIP; drop a TIPS that [TIPS reference data (S2)](./DataStores.md#s2) does not hold.
  - For every other security: to what [FedInvest (E1)](./DATA_DICTIONARY.md#e1) states, converting its `MM/DD/YYYY` maturity date to `YYYY-MM-DD`.

The three prices, and how Treasury derives them, are described in [FedInvest Pricing Logic](../YieldCurves/knowledge/FedInvest_Pricing_Logic.md).

**Output:** the [TIPS Prices](./DATA_DICTIONARY.md#tips-prices) and the [Treasury Prices](./DATA_DICTIONARY.md#treasury-prices), to [Calculate yields (1.1.3)](#calculate-yields).

<a id="calculate-yields"></a>
### 1.1.3 Calculate yields

**Implemented by:** `shared/src/fedinvest-prices.js#yieldForSecurity`, `shared/src/bond-math.js#yieldFromPrice`, `shared/src/fedinvest-prices.js#serializeS1`

Calculate the [Yield](./DATA_DICTIONARY.md#yield) of each TIPS and each Treasury [Select prices and add TIPS reference data (1.1.2)](#select-prices-and-add-tips-reference-data) produced, and write [FedInvest prices (S1)](./DataStores.md#s1):

- For each security, at the [Settlement Date](./DATA_DICTIONARY.md#settlement-date) that [Determine settlement date (1.1.1)](#determine-settlement-date) produced:
  - If it has no [Price](./DATA_DICTIONARY.md#price): write it with no [Yield](./DATA_DICTIONARY.md#yield).
  - Otherwise: calculate its [Yield](./DATA_DICTIONARY.md#yield) from its [Price](./DATA_DICTIONARY.md#price), the same yield-from-price calculation [Calculate TIPS yields (3.1.7)](../YieldCurves/knowledge/3.1_Parse_Sources_And_Calculate_Yields.md#calculate-tips-yields) and [Calculate Treasury yields (3.1.8)](../YieldCurves/knowledge/3.1_Parse_Sources_And_Calculate_Yields.md#calculate-treasury-yields) use for every other source and security type in the portal.
- Write [FedInvest prices (S1)](./DataStores.md#s1) in its [composition](./DATA_DICTIONARY.md#s1): the [Settlement Date](./DATA_DICTIONARY.md#settlement-date) on the first line, then a header line, then one line per security — its type, CUSIP, maturity, coupon, dated date Ref CPI, price and yield.

**Output:** [FedInvest prices (S1)](./DataStores.md#s1).

## A past trading day

`scripts/getFedInvestPricesForDate.js` is a separate, manually-run tool, not this scheduled process, for a realistic year-over-year test that needs per-CUSIP prices from a past date ([TipsLadderManager `KNOWN_ISSUES.md`](../TipsLadderManager/KNOWN_ISSUES.md) §Reproducing the year-over-year scenario). Given a date, on FedInvest's date-selection page rather than its daily endpoint:

- Recognize a line of that date's price table as a row the same way [Select prices and add TIPS reference data (1.1.2)](#select-prices-and-add-tips-reference-data) does, then keep the TIPS rows only — not the four types [Select prices and add TIPS reference data (1.1.2)](#select-prices-and-add-tips-reference-data) keeps for the daily job.
- Set each kept row's Coupon Rate, Maturity Date and dated date Ref CPI, and calculate its Yield, the same way [Select prices and add TIPS reference data (1.1.2)](#select-prices-and-add-tips-reference-data) and [Calculate yields (1.1.3)](#calculate-yields) do for a TIPS.
- Write a local file in [FedInvest prices (S1)](./DataStores.md#s1)'s composition, not [FedInvest prices (S1)](./DataStores.md#s1) itself, with the given date as its [Settlement Date](./DATA_DICTIONARY.md#settlement-date) — never a date [Determine settlement date (1.1.1)](#determine-settlement-date) extracted from the page.
  - Write nothing if FedInvest's page does not confirm that date, or its price table has no rows.
