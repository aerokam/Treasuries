# 1.1 Download FedInvest prices and calculate yields

**Specifies:** [1.1 Download FedInvest prices and calculate yields](/knowledge/DFD_LEVEL3_INGEST_FEDINVEST) and the three processes it decomposes into  
**Implemented by:** `scripts/getYieldsFedInvest.js`  
**Reference:** [FedInvest Pricing Logic](../YieldCurves/knowledge/FedInvest_Pricing_Logic.md), [FedInvest Treasury Pricing Methodology](../YieldCurves/knowledge/FedInvest_Treasury_Pricing_Methodology.md)

## Scope

Reads the [FedInvest Daily Price List](./DATA_DICTIONARY.md#fedinvest-daily-price-list) that [FedInvest (E1)](./DATA_DICTIONARY.md#e1) states, [TIPS reference data (S2)](./DataStores.md#s2) and the bond holidays, and writes [FedInvest prices (S1)](./DataStores.md#s1): the [Settlement Date](./DATA_DICTIONARY.md#settlement-date) of the prices, then one line for each TIPS and each market-based bill, note and bond, with one [Price](./DATA_DICTIONARY.md#price) and the [Yield](./DATA_DICTIONARY.md#yield) of that price at the [Settlement Date](./DATA_DICTIONARY.md#settlement-date).

- A TIPS takes its [Coupon Rate](./DATA_DICTIONARY.md#coupon-rate), [Maturity Date](./DATA_DICTIONARY.md#maturity-date) and dated date [Ref CPI](./DATA_DICTIONARY.md#ref-cpi) from [TIPS reference data (S2)](./DataStores.md#s2); a TIPS that [TIPS reference data (S2)](./DataStores.md#s2) does not hold is dropped.
- Every other security takes its [Coupon Rate](./DATA_DICTIONARY.md#coupon-rate) and [Maturity Date](./DATA_DICTIONARY.md#maturity-date) from [FedInvest (E1)](./DATA_DICTIONARY.md#e1).
- [FedInvest prices (S1)](./DataStores.md#s1) is not written on a [Bond Holiday](./DATA_DICTIONARY.md#bond-holiday), or when the price list does not state prices for the run date.

**A past trading day.** `scripts/getFedInvestPricesForDate.js` executes [Select prices and add TIPS reference data (1.1.2)](#select-prices-and-add-tips-reference-data) and [Calculate yields (1.1.3)](#calculate-yields) for the TIPS alone, on the price list FedInvest publishes for a past trading day, and writes a local file in [FedInvest prices (S1)](./DataStores.md#s1)'s composition rather than [FedInvest prices (S1)](./DataStores.md#s1) itself. Its settlement date is the date asked for, and the file is written only when the page states that date and its price table has rows.

## Processes

<a id="determine-settlement-date"></a>
### 1.1.1 Determine settlement date

**Implemented by:** `scripts/getYieldsFedInvest.js#determineSettlementDate`

Extracts a date from the [FedInvest (E1)](./DATA_DICTIONARY.md#e1) page and passes it to [Calculate yields (1.1.3)](#calculate-yields) as the [Settlement Date](./DATA_DICTIONARY.md#settlement-date):

- If the run date, in Eastern time, is a [Bond Holiday](./DATA_DICTIONARY.md#bond-holiday): stop here, passing no [Settlement Date](./DATA_DICTIONARY.md#settlement-date) onward. The run ends without a retry.
- Fetch the [FedInvest (E1)](./DATA_DICTIONARY.md#e1) page.
  - If its page text does not contain `Prices For:`: stop here, passing no [Settlement Date](./DATA_DICTIONARY.md#settlement-date) onward. The run ends without a retry — the page has not published a price list for the run date yet.
- Extract the date following `Prices For:` in the page text, in whichever of two forms it appears: `YYYY Mon D` (for example `2026 Mar 23`) or `Mon D, YYYY` (for example `Mar 23, 2026`), `Mon` a three-letter month abbreviation.
  - If the page's price table has no rows despite stating this date: the run ends as an uncaught failure.
- If the extracted date is not the run date: stop here, passing no [Settlement Date](./DATA_DICTIONARY.md#settlement-date) onward. The run ends as a failure, and the task retries ([Data_Pipeline.md](./Data_Pipeline.md) §2.0) — FedInvest is still showing a prior day's price list.
- Otherwise: pass the extracted date onward as the [Settlement Date](./DATA_DICTIONARY.md#settlement-date) itself (T+0) — unlike a market quote, which settles one bond trading day after its [Download Date](./DATA_DICTIONARY.md#download-date) (T+1, [Determine settlement date (3.1.6)](../YieldCurves/knowledge/3.1_Parse_Sources_And_Calculate_Yields.md#determine-settlement-date)).

**T+0 was determined empirically.** Yields calculated from FedInvest prices at T+0 come close to the yields of broker quotes settling at T+1. The developer established this in a spreadsheet comparison. No record of that measurement is held in this repository.

**Output:** the [Settlement Date](./DATA_DICTIONARY.md#settlement-date), to [Calculate yields (1.1.3)](#calculate-yields).

<a id="select-prices-and-add-tips-reference-data"></a>
### 1.1.2 Select prices and add TIPS reference data

**Implemented by:** `shared/src/fedinvest-prices.js#parseFedInvestPriceRows`, `shared/src/fedinvest-prices.js#selectPricedSecurity`

Reads the rows of the [FedInvest (E1)](./DATA_DICTIONARY.md#e1) price table and [TIPS reference data (S2)](./DataStores.md#s2), and produces the [TIPS Prices](./DATA_DICTIONARY.md#tips-prices) and the [Treasury Prices](./DATA_DICTIONARY.md#treasury-prices):

- Keep a row whose `SECURITY TYPE` is `TIPS`, `MARKET BASED BILL`, `MARKET BASED NOTE` or `MARKET BASED BOND`; drop every other row.
- Set the [Price](./DATA_DICTIONARY.md#price) to the `BUY` price, the `SELL` price where `BUY` is empty or zero, or the `END OF DAY` price where both are; a row with none of the three has no price.
- Take the [Coupon Rate](./DATA_DICTIONARY.md#coupon-rate) and the [Maturity Date](./DATA_DICTIONARY.md#maturity-date):
  - For a TIPS: take them, and the dated date [Ref CPI](./DATA_DICTIONARY.md#ref-cpi), from [TIPS reference data (S2)](./DataStores.md#s2) held for its CUSIP; drop a TIPS that [TIPS reference data (S2)](./DataStores.md#s2) does not hold.
  - For every other security: take them from what [FedInvest (E1)](./DATA_DICTIONARY.md#e1) states.

The three prices, and how Treasury derives them, are described in [FedInvest Pricing Logic](../YieldCurves/knowledge/FedInvest_Pricing_Logic.md).

**Output:** the [TIPS Prices](./DATA_DICTIONARY.md#tips-prices) and the [Treasury Prices](./DATA_DICTIONARY.md#treasury-prices), to [Calculate yields (1.1.3)](#calculate-yields).

<a id="calculate-yields"></a>
### 1.1.3 Calculate yields

**Implemented by:** `shared/src/fedinvest-prices.js#yieldForSecurity`, `shared/src/bond-math.js#yieldFromPrice`, `shared/src/fedinvest-prices.js#serializeS1`

Calculates the [Yield](./DATA_DICTIONARY.md#yield) of each TIPS and each Treasury from its [Price](./DATA_DICTIONARY.md#price) at the [Settlement Date](./DATA_DICTIONARY.md#settlement-date) from [Determine settlement date (1.1.1)](#determine-settlement-date), and writes [FedInvest prices (S1)](./DataStores.md#s1) in its [composition](./DATA_DICTIONARY.md#s1): the settlement date on the first line, then a header, then one line per security. A security with no price is written with no yield.

**Output:** [FedInvest prices (S1)](./DataStores.md#s1).
