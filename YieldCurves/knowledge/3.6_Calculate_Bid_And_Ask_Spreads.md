# 3.6 Calculate bid and ask spreads

**Specifies:** [3.6 Calculate bid and ask spreads](/knowledge/DFD_LEVEL2_YIELDCURVES)  
**Implemented by:** `shared/src/spreads.js#yieldSpreadBps`, `shared/src/spreads.js#priceSpreadPct`, `shared/src/spreads.js#addTipsSpreads`, `shared/src/spreads.js#addTreasurySpreads`  
**Input:** [TIPS Yields](../../knowledge/DATA_DICTIONARY.md#tips-yields) and [Treasury Yields](../../knowledge/DATA_DICTIONARY.md#treasury-yields), from [Parse sources and calculate yields (3.1)](./3.1_Parse_Sources_And_Calculate_Yields.md)  
**Output:** [Bid and Ask Spreads](../../knowledge/DATA_DICTIONARY.md#bid-and-ask-spreads), to [Render charts and tables (3.7)](./3.7_Render_Charts_And_Tables.md)

Read the [TIPS Yields](../../knowledge/DATA_DICTIONARY.md#tips-yields) and the [Treasury Yields](../../knowledge/DATA_DICTIONARY.md#treasury-yields) and produce the [Bid and Ask Spreads](../../knowledge/DATA_DICTIONARY.md#bid-and-ask-spreads) for each security quoted with both an ask and a bid [Price](../../knowledge/DATA_DICTIONARY.md#price):

- Only [Market quotes (S7)](../../knowledge/DATA_DICTIONARY.md#s7) state both an ask and a bid, so a security from [FedInvest prices (S1)](../../knowledge/DATA_DICTIONARY.md#s1) has no spread.

<a id="bid-ask-spreads"></a>
## Yield spread

- Calculate the Yield Spread: the bid [Yield](../../knowledge/DATA_DICTIONARY.md#yield) less the ask Yield, in basis points.
  - Both yields are calculated from price, the TIPS in [Calculate TIPS yields (3.1.7)](./3.1_Parse_Sources_And_Calculate_Yields.md#calculate-tips-yields) and the nominal Treasuries in [Calculate Treasury yields (3.1.8)](./3.1_Parse_Sources_And_Calculate_Yields.md#calculate-treasury-yields), so the two sides share one convention and their difference is a spread.
  - If either yield could not be calculated: there is no Yield Spread.

## Price spread

- Calculate the Price Spread: the ask [Price](../../knowledge/DATA_DICTIONARY.md#price) less the bid Price, as a percentage of the ask Price.
  - For a TIPS: use the [Adjusted Ask Price and Adjusted Bid Price](../../knowledge/DATA_DICTIONARY.md#adjusted-price), the amount that changes hands.
  - For a nominal Treasury: use the quoted prices.
  - If either price is missing, or the ask Price is not above zero: there is no Price Spread.

**Output:** the yield and price spreads per security, to [Render charts and tables (3.7)](./3.7_Render_Charts_And_Tables.md).
