# 7.1 Load CPI data

**Specifies:** [7.1 Load CPI data](/knowledge/DFD_LEVEL2_CPIEXPLORER)
**Implemented by:** `CpiExplorer/src/data.js`, `CpiExplorer/src/app.js` (`init`, `setDataStatus`), `shared/src/csv.js`
**Input:** [CPI history (S8)](../../knowledge/DATA_DICTIONARY.md#s8) and [Ref CPI (S3)](../../knowledge/DATA_DICTIONARY.md#s3)
**Output:** [Monthly CPI-U](../../knowledge/DATA_DICTIONARY.md#monthly-cpi-u) and [Daily Ref CPI](../../knowledge/DATA_DICTIONARY.md#daily-ref-cpi) to [Calculate CPI series (7.2)](./7.2_Calculate_CPI_Series.md) and [Render CPI chart (7.3)](./7.3_Render_CPI_Chart.md); [Charts and Tables](../../knowledge/DATA_DICTIONARY.md#charts-and-tables) to the user (the status line)

Read the two stores and pass their rows on. [Fetch CPI history (1.12)](../../knowledge/1.12_Fetch_CPI_History.md) writes S8 and [Fetch daily Ref CPI (1.13)](../../knowledge/1.13_Fetch_Daily_Ref_CPI.md) writes S3.

<a id="data-loading"></a>
When the page opens, fetch both stores in parallel with the browser cache bypassed, and parse each with `shared/src/csv.js#parseCsv`, reading the header names in lower case:

- Read [CPI history (S8)](../../knowledge/DATA_DICTIONARY.md#s8) as one row per month, oldest first, of `year`, `month`, `date`, `nsa` and `sa`.
  - Keep a row whose `Period` is `M01` through `M12`. Drop any other period code.
  - Set `month` to the period number, so `M01` is 1, and `date` to the first of that month in local time.
  - Set `nsa` or `sa` to null when its cell is blank or `-`. S8 leaves `SA` blank before January 1947.
- Read [Ref CPI (S3)](../../knowledge/DATA_DICTIONARY.md#s3) as one row per calendar day, oldest first, of `date` in local time and `value`. S3 begins 1997-01-15 and runs past the current date, because Treasury publishes the Ref CPI several weeks ahead. Drop a row whose date or value does not parse.
- Show the status "CPI through " and the month of the last S8 row, "  ·  Ref CPI through " and the date of the last S3 row.
- When either fetch fails, show the status "Load error: " and the reason, in red, and draw nothing.
