# CPI Explorer: Technical Spec

**Implemented by:** `CpiExplorer/src/data.js`, `CpiExplorer/src/calc.js`, `CpiExplorer/src/chart.js`, `CpiExplorer/src/app.js`, `CpiExplorer/index.html`

<a id="data-loading"></a>
## Data Loading

When the page opens, fetch both stores in parallel with the browser cache bypassed, and parse each with `shared/src/csv.js#parseCsv`, reading the header names in lower case:

- Read [CPI history (S8)](../../knowledge/DATA_DICTIONARY.md#s8) as one row per month, oldest first, of `year`, `month`, `date`, `nsa` and `sa`.
  - Keep a row whose `Period` is `M01` through `M12`. Drop any other period code.
  - Set `month` to the period number, so `M01` is 1, and `date` to the first of that month in local time.
  - Set `nsa` or `sa` to null when its cell is blank or `-`. S8 leaves `SA` blank before January 1947.
- Read [Ref CPI (S3)](../../knowledge/DATA_DICTIONARY.md#s3) as one row per calendar day, oldest first, of `date` in local time and `value`. S3 begins 1997-01-15 and runs past the current date, because Treasury publishes the Ref CPI several weeks ahead. Drop a row whose date or value does not parse.
- Show the status "CPI through " and the month of the last S8 row, "  ·  Ref CPI through " and the date of the last S3 row.
- When either fetch fails, show the status "Load error: " and the reason, in red, and draw nothing.

<a id="calculations"></a>
## Calculations

Each calculation returns `labels`, the dates as `YYYY-MM-DD`, and `values`. A monthly source is the S8 rows and the daily source is the S3 rows. A row with a null value for the series is skipped.

- **Index Level**: one point per row, the value itself.
- **Year-over-Year %**, the [CPI Change (Year-over-Year)](../../knowledge/DATA_DICTIONARY.md#cpi-change-yoy): `(value[t] / value[t − 12 months] − 1) × 100`.
- **Month-over-Month %**, the [CPI Change (Month-over-Month)](../../knowledge/DATA_DICTIONARY.md#cpi-change-mom): `(value[t] / value[t − 1 month] − 1) × 100`.
- **Rolling Window %**, the [Rolling CPI Change](../../knowledge/DATA_DICTIONARY.md#rolling-cpi-change) over N months: `(value[t] / value[t − N months] − 1) × 100`.
  - For the monthly source, the earlier value is the row 12, 1 or N rows back. The first 12, 1 or N rows have no point. A point is skipped when the earlier value is null or 0.
  - For the daily source, the earlier value is that of the last row dated on or before the same day of the month 12 months, 1 month or N months earlier, or the last day of that month when it has no such day. A row with no earlier row has no point.
- **Point-to-Point %**, the [CPI Change (Point-to-Point)](../../knowledge/DATA_DICTIONARY.md#cpi-change-p2p) between the start date and the end date of the date range:
  - Take the last row with a value dated on or before the start date, and the last row with a value dated on or before the end date. When either is missing, or the start value is 0, the result is empty.
  - Set `changePct` to `(end / start − 1) × 100`, with the values of those two rows.
  - Set `months` to the number of calendar months between those two rows.
  - Set `annualized` to the [CPI CAGR](../../knowledge/DATA_DICTIONARY.md#cpi-cagr), `((end / start)^(12 / months) − 1) × 100`, or to empty when `months` is 0.
  - Chart the index values of the rows from the start date to the end date, each as the percent change from the start value, so the line begins near 0% and ends at `changePct`.

<a id="controls"></a>
## Controls

- **Data source**: three checkboxes, Monthly CPI-U NSA (checked at first), Monthly CPI-U SA and Daily Ref CPI (1997+). One box always stays checked. Changing a source keeps the date range the user set.
- **Display mode**: five radio buttons, Index Level (at first), Year-over-Year %, Month-over-Month %, Rolling Window % and Point-to-Point %.
  - Show the Logarithmic Scale checkbox only for Index Level, because the other modes chart a percent series that a logarithmic axis cannot show. Changing to another mode clears it.
  - Changing the mode resets the zoom.
- **Rolling Window**, shown only for Rolling Window %: the presets 1Y, 2Y, 5Y, 10Y and 20Y set 12, 24, 60, 120 and 240 months. A custom number of months, applied 400 ms after the last keystroke when above 0, clears the preset highlight. The window starts at 12 months.
- **Date Range**, shown for every mode: Start and End date pickers (`shared/src/date-picker.js`) bounded to the extent of all three series, 1913-01-01 through the last Ref CPI date. Both start at that extent. Full History restores it. Changing a date resets the zoom.
- **Point-to-Point**, shown only for Point-to-Point %: for each selected source, a line "X.XX% total  |  X.XX% annualized", or "No data for selected range." when the result is empty. With more than one source selected each line begins with the source name in the colour of its chart line.
- **Reset Zoom**, in the header, shows the whole of the data again.

<a id="render"></a>
## Rendering

Draw on every change of a control, one line for each selected source:

- Resolve the date range from the pickers, or the extent of all three series where a picker is empty.
- For Point-to-Point %, take the line from the calculation of [Calculations](#calculations).
- For every other mode, run the calculation on the whole of the source, then keep the points dated within the date range, inclusive. A Year-over-Year % series therefore has a point from the first month of the range onward.
- Label the vertical axis "CPI Index", "Year-over-Year %", "Month-over-Month %", "Trailing Nm Change %" (N the months of the window) or "Point-to-Point %" by the mode.
- Colour the lines in the order selected: `#1a56db`, `#ea580c`, `#7c3aed`, `#059669`, `#dc2626`. Show the legend only with more than one line.
- Draw a dashed horizontal line at 0% in every mode except Index Level, so periods of rising and falling prices are visible. Leave it out when 0 is outside the visible vertical range.
- Format the tooltip date as "MMM d, yyyy" when the Daily Ref CPI is among the selected sources, and as "MMM yyyy" otherwise. Format the value to 2 decimal places.

<a id="chart"></a>
## Chart

**Implemented by:** `CpiExplorer/src/chart.js`, `shared/src/chart-keys.js`, `shared/src/chart-time-axis.js`

- Draw with Chart.js as a line chart on a time axis, without animation. Show the points as dots of radius 1.5 for a series of 500 points or fewer, and none above that.
- Place the ticks of the time axis with `calendarTimeAxis()` of `shared/src/chart-time-axis.js`, specified in [Visual Standards](../../YieldCurves/knowledge/Visual_Standards.md#time-aligned-x-axis).
- Snap the vertical axis bounds to the steps of `snapYBounds` (`shared/src/chart-keys.js`). On the logarithmic axis, set them to 0.95 times the lowest and 1.05 times the highest visible value, leaving out values at or below 0.
- Zoom and pan on both axes with the mouse wheel, a pinch and a drag, and with the arrow keys, + and − (`handleChartKeydown`). After each zoom or pan, rescale the vertical axis to the points in the visible dates.
- Keep the zoom when a source is added or removed. Reset it when a date or the mode changes.
